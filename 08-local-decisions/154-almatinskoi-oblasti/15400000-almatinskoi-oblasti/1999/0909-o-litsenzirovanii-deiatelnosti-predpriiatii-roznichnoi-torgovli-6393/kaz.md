# Алкоголь өнімдерін бөлшектеп сату кәсіпорындары қызметін лицензиялау туралы

> *Ескерту. Күші жойылды - Алматы облысы әкімінің 24.08.2004 № 8-87 шешімімен.*

Қазақстан Республикасының 1999 ж. шілденің 16-ғы "Этил спирті мен алкоголь өнімдерін шығаруды және олардың айналымын мемлекеттік реттеу туралы" N 429-1 Заңына сәйкес және Қазақстан Республикасы Үкіметінің 1999 ж. тамыздың 27-гі "Этил спирті мен алкоголь өнімдерін шығаруды лицензиялау, этил спиртін сақтау және сату, алкоголь өнімдерін (сырадан басқа) сақтау және көтеріп сату, сондай-ақ алкоголь өнімдерін (сырадан басқа) бөлшектеп сату Ережелерін бекіту туралы" N 1258, сондай-ақ 1999 ж. тамыздың 20-ғы "Қазақстан Республикасы Министрлер Кабинетінің 1995 ж. тамыздың 16-ғы N 1127 Қаулысына толықтыру енгізу туралы" N 1218 Қаулыларын жүзеге асыру мақсатында облыс Әкімі ШЕШІМ ҚАБЫЛДАДЫ:

1. Алкоголь өнімдерін (сырадан басқа) бөлшектеп сату қызметінің лицензиялары (лицензия берушілер) болып аудандардың, Қапшағай, Текелі, Талдықорған қалаларының әкімдері белгіленсін.

2. Алматы облысы Әкімінің 1999 ж. қаңтардың 14-гі "Құрамында 12%-тен астам этил спирті бар алкоголь өнімдерін Алматы облысының аумағында бөлшектеп сату Тәртібін бекіту туралы" N 1-9 шешімі күшін жойған болып саналсын.

3. Облыстық сауда және қызмет көрсету салалары кәсіпорындарының қызметін үйлестіру мен бақылау жөніндегі бөлім (Қ.Р. Ғалиева), Санитарлық-эпидемиологиялық қадағалау басқармасы (Ә.Қ. Талқымбаев) сауданың ұйымдастырылуына және сатылатын өнімнің сапасына бақылауды күшейтсін.

4. Осы шешімнің орындалуын бақылау облыс Әкімінің орынбасары А. Кәримоллинге жүктелсін.

5. Бұл шешім Әділет басқармасында мемлекеттік тіркеуден өткен сәттен бастап күшіне енеді.
