# Облыстың жалпы білім беретін мектептері сыныптарын толықтыру туралы

> *Ескерту. Күші жойылды - Алматы облыстық әкімінің 13.12.2004 № 12-114 шешімімен.*

“Білім туралы” Заңды жүзеге асыру және жалпы білім беретін мектептердің жүйесін реттеу мақсатында облыс Әкімі ШЕШІМ қабылдады:

<a id="para_1"></a>

1. Оқушылар контингентінің азаюына байланысты:

   -Ақсу ауданындағы Ақтөбе бастауыш мектебі;

   -Ақсу ауданындағы Қарасу бастауыш мектебі жабылсын.

<a id="para_2"></a>

2. Аудандық, калалық бюджет есебіндегі жалпы білім беретін мектептердің сыныптарын толықтыру, олардағы оқушылар контингенті №1-№19 қосымшаларға сәйкес бекітілсін.

<a id="para_3"></a>

3. Кейбір пәндерді терендетіп оқытатын жалпы білім беретін мектептер жүйесі № 20 қосымшаға сәйкес бекітілсін.

<a id="para_4"></a>

4. Осы шешімнің орындалуын бақылау облыс Әкімінің орынбасары А.Баталовқа жүктелсін.
