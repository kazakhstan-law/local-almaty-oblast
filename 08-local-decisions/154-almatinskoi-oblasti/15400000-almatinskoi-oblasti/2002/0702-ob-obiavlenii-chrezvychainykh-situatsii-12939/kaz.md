# Төтенше жағдай жариялау туралы

> *Ескерту. Күші жойылды - Алматы облыстық әкімінің 02.06.2004 № 6-58 шешімімен.*

Жанбырдың коп жаууы салдарынан Көксу өзені суының деңгейі күрт көтеріліп, су өту деңгейі секундына 530 текше метрге жетті. «Көксу-Арна» ЖШС-н аумағын, Кеңарал ауылындағы «Еңбекші ауылшаруашылығы кооперативінің епсін су тасқыны алып кеткен. Жауының тоқтамауына байланысты Ескелді, Көксу аудандарының күшімен салынған қорғау дамбаларын су шайып жатыр. Алматы-Өскемен автожол көпірінің екінші аралығынын істен шығу каупі төнуде. Көпірді 1994 жылы істен шыққан бірінші аралығы күні бүгінге дейін қалпына келтірілмеген.

Қазакстан Республикасы «Төтенше жағдайлар туралы» Заңының 19- бабындағы 5-тарауға сәйкес облыс Әкімі ШЕШIМ қабылдады:

<a id="p1"></a>

1. Көксу өзенінің су жайылған аумағында төтенше жағдай жариялансын.

<a id="p2"></a>

2. Көксу ауданының әкімі С.С.Қасенов, өз резерві есебінен «Көксу- Арна» ЖШС-і, Кеңарал ауылы аумағындағы Көксу өзені арнасының жағасын нығайту жұмыстарын жүргізсін. Су ағынын бағыттайтын төрт дамба орнатып, судын бір бөлігін Көксу өзенінің екінші арнасына бағыттасын.

<a id="p3"></a>

3. Ескелді ауданынын әкімі С.М.Дүйсембінов, өз резерві есебінен екінші автожол көпірінің аумағында өзен жағасын нығайту жұмыстарын жүргізсін.

<a id="p4"></a>

4. Облыстық автомобиль жолдары басқармасының бастығы Ш.Меренков бірінші автожол көпірінен екіншісіне су бұру үшін, су ағынын бағыттайтын дамба салсын.

<a id="p5"></a>

5. Қазакстан Реопубликасыныц Үкіметі мен Қазакстаи Республикасы көлік және коммуникация министрлігінен, ісген шыккан автожол көпірін алпына келтіру және өзен жағасын нығайту жұмыстары кешенін жүзеге сыру үшін 90 млн. теңгенің бөлінуі сұралсын.

<a id="p6"></a>

6. Осы шешімнің орындалу барысын бақылау облыс Әкімінін бірінші орынбасары В.Долженковка жүктелсін.

**Облыс әкімі**

**Ш.Құлмаханов**
