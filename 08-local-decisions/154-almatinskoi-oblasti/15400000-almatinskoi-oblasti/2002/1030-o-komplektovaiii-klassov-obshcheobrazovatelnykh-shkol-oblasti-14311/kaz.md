# Облыстың жалпы білім беретін мектептеріндегі сыныптарды комплектілеу туралы

«Білім туралы» Заңды жүзеге асыру және жалпы білім беретін мектептер жүйесін реттеу мақсатында облыс Әкімі ШЕШІМ қабылдады:

<a id="p1"></a>

1. № 1-19 қосымшаға сәйкес ауданды, қалалық бюджеттің есебінен қамтамасыз етілетін жалпы білім беретін мектептердің сынып комплектілері және оқушылар контингенті бекітілсін.

<a id="p2"></a>

2. № 20 қосымшаға сәйкес жекелеген пәндерді тереңдетіп оқытатын жалпы білім беретін мектептердің жүйесі бекітілсін.

<a id="p3"></a>

3. № 21 қосымшаға сәйкес гимназия жэне лицей сыныптар комплектісінің саны бекітілсін

<a id="p4"></a>

4. Осы шешімнін орындалуын бақылау облыс Әкімінің кеңесшісі С.М.Мұқановқа жүктелсін.

   **Облыс Әкімі**

   **Ш. Құлмаханов**
