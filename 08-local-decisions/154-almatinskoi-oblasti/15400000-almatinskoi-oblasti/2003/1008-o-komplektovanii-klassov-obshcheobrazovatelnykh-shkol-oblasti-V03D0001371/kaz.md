# Облыстың жалпы білім беретін мектептеріндегі сыныптарды толықтыру туралы

> *Ескерту. Күші жойылды - Алматы облысы әкімінің 29.12.2004 № 12-122 шешімімен.*

Қазақстан Республикасы «Білім туралы» Заңын жүзеге асыру және жалпы білім беретін мектептер жүйерін реттеу мақсатында облыс Әкімі ШЕШІМ қабылдады :

<a id="para_1"></a>

1. Аудандық қалалық бюджеттер есебінен ұсталатын жалпы білім беретін мектептердің сынып комплектілері және оқушылар континтенті № 1 -19 қосымшаға сәйкес бекітілсін.

<a id="para_2"></a>

2. Жекелеген пәндерді терендетіп оқытатын жалпы білім беретін мектептердің жүйесі № 20 қосымшаға сәйкес бекітілсін.

<a id="para_3"></a>

3. Гимназия және лицей сыныптары комплектісінің саны № 21 қосымшаға сәйкес бекітілсін.

<a id="para_4"></a>

4. Осы шешімнің орындалуын бақылау облыс Әкімінің кеңесшісі С.М. Мұқановқа жүктелсін.
