# Ауыл шаруашылығы тауарын өндірушілерге 2012 жылға арналған су беру жөніндегі субсидия көлемін айқындау туралы

РҚАО ескертпесі.

Мәтінде авторлық орфография және пунктуация сақталған.

"Қазақстан Республикасындағы жергілікті мемлекеттік басқару және өзін-өзі басқару туралы" Қазақстан Республикасының 2001 жылғы 23 қаңтардағы Заңына, Қазақстан Республикасы Үкіметінің 2006 жылғы 4 сәуірдегі N 237 қаулысымен бекітілген "Ауыл шаруашылығы тауарын өндірушілерге су беру жөніндегі қызметтердің құнын субсидиялау" ережесінің 8-тармағына сәйкес облыс әкімі ШЕШІМ ЕТТІ:

<a id="p1"></a>

1. Ауыл шаруашылығы тауарын өндірушілерге 2012 жылға арналған су беру жөніндегі субсидия көлемдері қосымшаға сәйкес айқындалсын.

<a id="p2"></a>

2. Жергілікті бюджеттен субсидиялауды "Алматы облысының ауыл шаруашылығы басқармасы" (Б.Б.Әлиев) мемлекеттік мекемесі жүргізсін.

<a id="p3"></a>

3. Осы шешімнің орындалуын бақылау облыс әкімінің орынбасары Т. Досымбековке жүктелсін.

<a id="p4"></a>

4. Осы шешім әділет органдарында мемлекеттік тіркелген күннен бастап күшіне енеді және алғаш ресми жарияланғаннан кейін күнтізбелік он күн өткен соң қолданысқа енгізіледі.

*Облыс әкімі А. Мұсаханов*

> *Облыс әкімінің 2012 жылғы*  
> *16 қазандағы "Ауыл шаруашылығы*  
> *тауарын өндірушілерге 2012 жылға*  
> *арналған су беру жөніндегі*  
> *субсидия көлемін айқындау*  
> *туралы" N 11-10 шешіміне*  
> *қосымша*
