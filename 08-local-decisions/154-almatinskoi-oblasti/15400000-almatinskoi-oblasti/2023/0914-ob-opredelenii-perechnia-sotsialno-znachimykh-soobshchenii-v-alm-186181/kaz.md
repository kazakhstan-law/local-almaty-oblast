# Алматы облысында әлеуметтік маңызы бар қатынастардың тізбесін айқындау туралы

«Автомобиль көлігі туралы» Қазақстан Республикасы Заңының 14-бабы 1-тармағының 5) тармақшасына сәйкес, Алматы облыстық мәслихаты ШЕШТІ:

<a id="p1"></a>

1. Алматы облысында әлеуметтік маңызы бар қатынастардың тізбесі осы шешімнің қосымшасына сәйкес айқындалсын.

<a id="p2"></a>

2. Алматы облыстық мәслихатының 2018 жылғы 13 қарашадағы «Алматы облысында әлеуметтік маңызы бар қатынастардың тізбесін айқындау туралы» № 37-204 (Нормативтік құқықтық актілерді мемлекеттік тіркеу тізілімінде № 4959 болып тіркелген) шешімінің күші жойылды деп танылсын.

<a id="p3"></a>

3. Осы шешімнің орындалуын бақылау Алматы облыстық мәслихатының тұрғын-үй коммуналдық шаруашылығы, құрылыс, сәулет және көліктік-логистикалық инфрақұрылым мәселелері бойынша тұрақты комиссиясына жүктелсін.

<a id="p4"></a>

4. Осы шешім оның алғашқы ресми жарияланған күнінен кейін күнтізбелік он күн өткен соң қолданысқа енгізіледі.

   **Алматы облыстық мәслихатының төрағасы**

   **Т. Байедилов**

> *Алматы облыстық мәслихатының 2023 жылғы 14 қыркүйектегі № 6-38*
