# Талдықорған қаласының 2017-2019 жылдарға арналған бюджеті туралы

2008 жылғы 4 желтоқсандағы Қазақстан Республикасының Бюджет кодексінің 9-бабының 2-тармағына, «Қазақстан Республикасындағы жергілікті мемлекеттік басқару және өзін-өзі басқару туралы» 2001 жылғы 23 қаңтардағы Қазақстан Республикасы Заңының 6-бабының 1-тармағының 1) тармақшасына сәйкес, Талдықорған қалалық мәслихаты ШЕШІМ ҚАБЫЛДАДЫ:

<a id="p1"></a>

1. 2017-2019 жылдарға арналған қала бюджеті тиісінше 1, 2, 3-қосымшаларға сәйкес, оның ішінде 2017 жылға келесі көлемдерде бекітілсін:

   1) кірістер 31408833 мың теңге, оның ішінде:

      салықтық түсімдер 2892051 мың теңге;

      салықтық емес түсімдер 335499 мың теңге;

      негізгі капиталды сатудан түсетін түсімдер 139579 мың теңге;

      трансферттер түсімі 28041704 мың теңге, оның ішінде:

      ағымдағы нысаналы трансферттер 8797801 мың теңге;

      нысаналы даму трансферттері 7299068 мың теңге;

      субвенциялар 11944835 мың теңге;

   2) шығындар 33855100 мың теңге;

   3) таза бюджеттік кредиттеу 1697197 мың теңге, оның ішінде:

      бюджеттік кредиттер 1701192 мың теңге;

      бюджеттік кредиттерді өтеу 3995 мың теңге;

   4) қаржы активтерімен операциялар бойынша сальдо 0 теңге;

   5) бюджет тапшылығы (профициті) (-) 4143464 мың теңге;

   6) бюджет тапшылығын қаржыландыру (профицитін пайдалану) 4143464 мың теңге.

> *Ескерту. 1-тармақ жаңа редакцияда - Алматы облысы Талдықорған қалалық мәслихатының 17.08.2017 № 111 (01.01.2017 бастап қолданысқа енгізіледі) шешімімен.*

<a id="p2"></a>

2. Қаланың жергілікті атқарушы органының 2017 жылға арналған резерві 16502 мың теңге сомасында бекітілсін.

<a id="p3"></a>

3. 2017 жылға арналған қалалық бюджетте жергілікті өзін-өзі басқару органдарына 4-қосымшаға сәйкес 56894 мың теңге сомасында трансферттер көзделгені ескерілсін.

   Ауылдық округтер әкімдері жергілікті өзін-өзі басқарудың қолма-қол ақшаны бақылау шотына түсетін бюджет қаражатының тиімді пайдаланылуын қамтамасыз етсін.

<a id="p4"></a>

4. 2017 жылға арналған қалалық бюджетті атқару процесінде секвестрлеуге жатпайтын қалалық бюджеттік бағдарламалардың тізбесі 5-қосымшаға сәйкес белгіленсін.

<a id="p5"></a>

5. Осы шешімнің орындалуын бақылау Талдықорған қалалық мәслихатының «Экономика, қаржы мәселелері және бюджет жөніндегі» тұрақты комиссиясына жүктелсін.

<a id="p6"></a>

6. Осы шешім 2017 жылғы 1 қаңтардан бастап қолданысқа енгізіледі.
