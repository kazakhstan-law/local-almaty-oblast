# Талдықорған қаласының ауылдық округтерінің 2018-2020 жылдарға арналған бюджеттері туралы

2008 жылғы 4 желтоқсандағы Қазақстан Республикасы Бюджет Кодексінің 9-1-бабының 2-тармағына, «Қазақстан Республикасындағы жергілікті мемлекеттік басқару және өзін-өзі басқару туралы» 2001 жылдың 23 қаңтардағы Қазақстан Республикасының Заңының 6-бабының 1-тармағының 1) тармақшасына сәйкес, Талдықорған қалалық мәслихаты ШЕШІМ ҚАБЫЛДАДЫ:

<a id="p1"></a>

1. 2018-2020 жылдарға арналған Еркін ауылдық округінің бюджеті тиісінше осы шешімнің 1, 2 және 3-қосымшаларына сәйкес, оның ішінде 2018 жылға келесі көлемдерде бекітілсін:

   1) кірістер 95322 мың теңге, оның ішінде:

      салықтық түсімдер 20892 мың теңге;

      трансферттер түсімі 74430 мың теңге, оның ішінде:

      ағымдағы нысаналы трансферттер 11068 мың теңге;

      субвенциялар 63362 мың теңге;

   2) шығындар 95322 мың теңге;

   3) таза бюджеттік кредиттеу 0 теңге, оның ішінде:

      бюджеттік кредиттер 0 теңге;

      бюджеттік кредиттерді өтеу 0 теңге;

   4) қаржы активтерімен операциялар бойынша сальдо 0 теңге;

   5) бюджет тапшылығы (профициті) (-) 0 теңге;

   6) бюджет тапшылығын қаржыландыру (профицитін пайдалану) 0 теңге.

<a id="p2"></a>

2. 2018-2020 жылдарға арналған Өтенай ауылдық округінің бюджеті тиісінше осы шешімнің 4, 5 және 6-қосымшаларына сәйкес, оның ішінде 2018 жылға келесі көлемдерде бекітілсін:

   1) кірістер 72892 мың теңге, оның ішінде:

      салықтық түсімдер 18305 мың теңге;

      трансферттер түсімі 54587 мың теңге, оның ішінде:

      ағымдағы нысаналы трансферттер 10453 мың теңге;

      субвенциялар 44134 мың теңге;

   2) шығындар 72892 мың теңге;

   3) таза бюджеттік кредиттеу 0 теңге, оның ішінде:

      бюджеттік кредиттер 0 теңге;

      бюджеттік кредиттерді өтеу 0 теңге;

   4) қаржы активтерімен операциялар бойынша сальдо 0 теңге;

   5) бюджет тапшылығы (профициті) (-) 0 теңге;

   6) бюджет тапшылығын қаржыландыру (профицитін пайдалану) 0 теңге.

<a id="p3"></a>

3. Осы шешімнің орындалуын бақылау Талдықорған қалалық мәслихатының «Экономика, қаржы мәселелері және бюджет жөніндегі» тұрақты комиссиясына жүктелсін.

<a id="p4"></a>

4. Осы шешім 2018 жылғы 1 қаңтардан бастап қолданысқа енгізіледі.
