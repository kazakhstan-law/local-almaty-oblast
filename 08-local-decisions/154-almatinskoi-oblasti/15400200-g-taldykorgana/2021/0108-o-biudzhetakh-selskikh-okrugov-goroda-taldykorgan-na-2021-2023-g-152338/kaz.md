# Талдықорған қаласының ауылдық округтерінің 2021-2023 жылдарға арналған бюджеттері туралы

> *Ескерту. 01.01.2021 бастап қолданысқа енгізіледі - осы шешімнің 4-тармағымен.*

2008 жылдың 4 желтоқсандағы Қазақстан Республикасы Бюджет Кодексінің 9-1-бабының 2-тармағына, «Қазақстан Республикасындағы жергілікті мемлекеттік басқару және өзін-өзі басқару туралы» 2001 жылғы 23 қаңтардағы Қазақстан Республикасы Заңының 6-бабының 1-тармағының 1) тармақшасына сәйкес, Талдықорған қалалық мәслихаты ШЕШІМ ҚАБЫЛДАДЫ:

<a id="p1"></a>

1. 2021-2023 жылдарға арналған Еркін ауылдық округінің бюджеті тиісінше осы шешімнің 1, 2 және 3-қосымшаларына сәйкес, оның ішінде 2020 жылға келесі көлемдерде бекітілсін:

   1) кірістер 201 349 мың теңге, оның ішінде:

      салықтық түсімдер 48 235 мың теңге;

      трансферттер түсімі 153 114 мың теңге, оның ішінде:

   2) шығындар 216 107 мың теңге;

   3) таза бюджеттік кредиттеу 0 теңге, оның ішінде:

      бюджеттік кредиттер 0 теңге;

      бюджеттік кредиттерді өтеу 0 теңге;

   4) қаржы активтерімен операциялар бойынша сальдо 0 теңге;

      қаржы активтерін сатып алу 0 теңге;

      мемлекеттің қаржы активтерін сатудан түсетін түсімдер 0 теңге;

   5) бюджет тапшылығы (профициті) (-) 14 758 мың теңге;

   6) бюджет тапшылығын қаржыландыру (профицитін пайдалану) 14 758 мың теңге;

      қарыздар түсімі 0 теңге;

      қарыздарды өтеу 0 теңге;

      бюджет қаражатының пайдаланылатын қалдықтары 14 758 мың теңге.

      > *Ескерту. 1-тармақ жаңа редакцияда – Алматы облысы Талдықорған қалалық мәслихатының 08.06.2021 № 50 (01.01.2021 бастап қолданысқа енгізіледі); 26.08.2021 № 70 (01.01.2021 бастап қолданысқа енгізіледі) шешімдерімен.*

<a id="p2"></a>

2. 2021-2023 жылдарға арналған Өтенай ауылдық округінің бюджеті тиісінше осы шешімнің 4, 5 және 6-қосымшаларына сәйкес, оның ішінде 2021 жылға келесі көлемдерде бекітілсін:

   1) кірістер 204 346 мың теңге, оның ішінде:

      салықтық түсімдер 60 168 мың теңге;

      трансферттер түсімі 144 178 мың теңге, оның ішінде:

   2) шығындар 239 092 мың теңге;

   3) таза бюджеттік кредиттеу 0 теңге, оның ішінде:

      бюджеттік кредиттер 0 теңге;

      бюджеттік кредиттерді өтеу 0 теңге;

   4) қаржы активтерімен операциялар бойынша сальдо 0 теңге;

      қаржы активтерін сатып алу 0 теңге;

      мемлекеттің қаржы активтерін сатудан түсетін түсімдер 0 теңге;

   5) бюджет тапшылығы (профициті) (-) 34 746 мың теңге;

   6) бюджет тапшылығын қаржыландыру (профицитін пайдалану) 34 746 мың теңге;

      қарыздар түсімі 0 теңге;

      қарыздарды өтеу 0 теңге;

      бюджет қаражатының пайдаланылатын қалдықтары 34 746 мың теңге.

      > *Ескерту. 2-тармақ жаңа редакцияда – Алматы облысы Талдықорған қалалық мәслихатының 08.06.2021 № 50 (01.01.2021 бастап қолданысқа енгізіледі); 26.08.2021 № 70 (01.01.2021 бастап қолданысқа енгізіледі) шешімдерімен.*

<a id="p3"></a>

3. Осы шешімнің орындалуын бақылау Талдықорған қалалық мәслихатының «Экономика, қаржы мәселелері және бюджет жөніндегі» тұрақты комиссиясына жүктелсін.

<a id="p4"></a>

4. Осы шешім 2021 жылғы 1 қаңтардан бастап қолданысқа енгізіледі.
