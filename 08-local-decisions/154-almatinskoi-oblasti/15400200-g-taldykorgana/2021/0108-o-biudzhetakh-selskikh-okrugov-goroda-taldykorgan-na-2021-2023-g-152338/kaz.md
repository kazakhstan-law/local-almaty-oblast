# Талдықорған қаласының ауылдық округтерінің 2021-2023 жылдарға арналған бюджеттері туралы

> *Ескерту. 01.01.2021 бастап қолданысқа енгізіледі - осы шешімнің 4-тармағымен.*

2008 жылдың 4 желтоқсандағы Қазақстан Республикасы Бюджет Кодексінің 9-1-бабының 2-тармағына, «Қазақстан Республикасындағы жергілікті мемлекеттік басқару және өзін-өзі басқару туралы» 2001 жылғы 23 қаңтардағы Қазақстан Республикасы Заңының 6-бабының 1-тармағының 1) тармақшасына сәйкес, Талдықорған қалалық мәслихаты ШЕШІМ ҚАБЫЛДАДЫ:

1. 2021-2023 жылдарға арналған Еркін ауылдық округінің бюджеті тиісінше осы шешімнің 1, 2 және 3-қосымшаларына сәйкес, оның ішінде 2021 жылға келесі көлемдерде бекітілсін:

   1) кірістер 196 590 мың теңге, оның ішінде:

      салықтық түсімдер 48 235 мың теңге;

      салықтық емес түсімдер 0 теңге;

      негізгі капиталды сатудан түсетін түсімдер 0 теңге;

      трансферттер түсімі 148 355 мың теңге, оның ішінде:

   2) шығындар 196 590 мың теңге;

   3) таза бюджеттік кредиттеу 0 теңге, оның ішінде:

      бюджеттік кредиттер 0 теңге;

      бюджеттік кредиттерді өтеу 0 теңге;

   4) қаржы активтерімен операциялар бойынша сальдо 0 теңге;

      қаржы активтерін сатып алу 0 теңге;

      мемлекеттің қаржы активтерін сатудан түсетін түсімдер 0 теңге;

   5) бюджет тапшылығы (профициті) (-) 0 теңге;

   6) бюджет тапшылығын қаржыландыру (профицитін пайдалану) 0 теңге;

      қарыздар түсімі 0 теңге;

      қарыздарды өтеу 0 теңге;

      бюджет қаражатының пайдаланылатын қалдықтары 0 теңге.

2. 2021-2023 жылдарға арналған Өтенай ауылдық округінің бюджеті тиісінше осы шешімнің 4, 5 және 6-қосымшаларына сәйкес, оның ішінде 2021 жылға келесі көлемдерде бекітілсін:

   1) кірістер 195 401 мың теңге, оның ішінде:

      салықтық түсімдер 60 168 мың теңге;

      салықтық емес түсімдер 0 теңге;

      негізгі капиталды сатудан түсетін түсімдер 0 теңге;

      трансферттер түсімі 135 233 мың теңге, оның ішінде:

   2) шығындар 195 401 мың теңге;

   3) таза бюджеттік кредиттеу 0 теңге, оның ішінде:

      бюджеттік кредиттер 0 теңге;

      бюджеттік кредиттерді өтеу 0 теңге;

   4) қаржы активтерімен операциялар бойынша сальдо 0 теңге;

      қаржы активтерін сатып алу 0 теңге;

      мемлекеттің қаржы активтерін сатудан түсетін түсімдер 0 теңге;

   5) бюджет тапшылығы (профициті) (-) 0 теңге;

   6) бюджет тапшылығын қаржыландыру (профицитін пайдалану) 0 теңге;

      қарыздар түсімі 0 теңге;

      қарыздарды өтеу 0 теңге;

      бюджет қаражатының пайдаланылатын қалдықтары 0 теңге.

3. Осы шешімнің орындалуын бақылау Талдықорған қалалық мәслихатының «Экономика, қаржы мәселелері және бюджет жөніндегі» тұрақты комиссиясына жүктелсін.

4. Осы шешім 2021 жылғы 1 қаңтардан бастап қолданысқа енгізіледі.
