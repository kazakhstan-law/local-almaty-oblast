# Сарқан ауданының Сарқан қаласы мен ауылдық округтерінің 2018-2020 жылдарға арналған бюджеттері туралы

2008 жылғы 4 желтоқсандағы Қазақстан Республикасының Бюджет кодексінің 9-1-бабының 2-тармағына, «Қазақстан Республикасындағы жергілікті мемлекеттік басқару және өзін-өзі басқару туралы» 2001 жылғы 23 қаңтардағы Қазақстан Республикасы Заңының 6-бабының 1-тармағының 1) тармақшасына сәйкес, Сарқан аудандық мәслихаты ШЕШІМ ҚАБЫЛДАДЫ:

1. 2018-2020 жылдарға арналған Сарқан қаласының бюджеті тиісінше осы шешімнің 1, 2, 3-қосымшаларына сәйкес, оның ішінде 2018 жылға келесі көлемдерде бекітілсін:

   1) кірістер 153 595 мың теңге, оның ішінде:

      салықтық түсімдер 73 271 мың теңге;

      салықтық емес түсімдер 0 теңге;

      негізгі капиталды сатудан түсетін түсімдер 0 теңге;

      трансферттердің түсімдері 80 324 мың теңге, оның ішінде:

      ағымдағы нысаналы трансферттер 41 117 мың теңге;

      нысаналы даму трансферттері 0 теңге;

      субвенциялар 39 207 мың теңге;

   2) шығындар 153 595 мың теңге.

   3) таза бюджеттік кредиттеу 0 теңге, оның ішінде:

      бюджеттік кредиттер 0 теңге;

      бюджеттік кредиттерді өтеу 0 теңге;

   4) қаржы активтерімен операциялар бойынша сальдо 0 теңге;

   5) бюджет тапшылығы (профициті) (-) 0 теңге;

   6) бюджет тапшылығын қаржыландыру (профицитін пайдалану) 0 теңге.

> *Ескерту. 1-тармақ жаңа редакцияда - Алматы облысы Сарқан аудандық мәслихатының 14.03.2018 № 34-149 (01.01.2018 бастап қолданысқа енгізіледі) шешімімен.*
