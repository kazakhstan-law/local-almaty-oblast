# Жастар ауылындағы Учхоз көшесінің атауын өзгерту туралы

Қазақстан Республикасының "Қазақстан Республикасындағы әкімшілік–аумақтық құрылысы туралы" Заңының 14-бабының 4)-тармақшасына сәйкес, Ескелді аудандық ономастика кеңесінің келісімі мен тиісті аумақ халқының пікірін ескере отырып Алдабергенов ауылдық округі әкімі ШЕШІМ ЕТЕДІ:

<a id="p1"></a>

1. Жастар ауылындағы Учхоз көшесінің атауы Бақты Ниязбеков көшесі атауына өзгертілсін.

<a id="p2"></a>

2. Осы шешімнің орындалуын қадағалау Алдабергенов ауылдық округі әкімінің орынбасары М.Н.Байшапановқа жүктелсін.

<a id="p3"></a>

3. Осы шешім алғашқы ресми жарияланғаннан кейін күнтізбелік он күн өткеннен сон қолданысқа енгізілсін.

**Алдабергенов ауылдық округінің әкімі**

**Т. Мусапиров**
