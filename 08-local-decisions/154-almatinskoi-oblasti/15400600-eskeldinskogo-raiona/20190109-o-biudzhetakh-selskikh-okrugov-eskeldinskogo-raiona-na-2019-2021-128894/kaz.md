# Ескелді ауданының ауылдық округтерінің 2019-2021 жылдарға арналған бюджеттері туралы

2008 жылғы 4 желтоқсандағы Қазақстан Республикасының Бюджет кодексінің 9-1-бабының 2-тармағына, «Қазақстан Республикасындағы жергілікті мемлекеттік басқару және өзін-өзі басқару туралы» 2001 жылғы 23 қаңтардағы Қазақстан Республикасы Заңының 6-бабының 1-тармағының 1) тармақшасына сәйкес, Ескелді аудандық мәслихаты ШЕШІМ ҚАБЫЛДАДЫ:

1. 2019-2021 жылдарға арналған Алдабергенов ауылдық округінің бюджеті тиісінше осы шешімнің 1, 2, 3-қосымшаларына сәйкес, оның ішінде 2019 жылға келесі көлемдерде бекітілсін:

   1) кірістер 59104 мың теңге, оның ішінде:

      салықтық түсімдер 12215 мың теңге;

      трансферттер түсімі 46889 мың теңге, оның ішінде:

      ағымдағы нысаналы трансферттер 11672 мың теңге;

      субвенциялар 35217 мың теңге;

   2) шығындар 59104 мың теңге;

   3) таза бюджеттік кредиттеу 0 теңге;

   4) қаржы активтерімен операциялар бойынша сальдо 0 теңге;

   5) бюджет тапшылығы (профициті) (-) 0 теңге;

   6) бюджет тапшылығын қаржыландыру (профицитін пайдалану) 0 теңге.

2. 2019-2021 жылдарға арналған Ақын Сара ауылдық округінің бюджеті тиісінше осы шешімнің 4, 5, 6-қосымшаларына сәйкес, оның ішінде 2019 жылға келесі көлемдерде бекітілсін:

   1) кірістер 48 466 мың теңге, оның ішінде:

      салықтық түсімдер 3 068 мың теңге;

      трансферттердің түсімдері 45 398 мың теңге, оның ішінде:

      ағымдағы нысаналы трансферттер 31 145 мың теңге;

      субвенциялар 14 253 мың теңге;

   2) шығындар 48 466 мың теңге;

   3) таза бюджеттік кредиттеу 0 теңге;

   4) қаржы активтерімен операциялар бойынша сальдо 0 теңге;

   5) бюджет тапшылығы (профициті) (-) 0 теңге;

   6) бюджет тапшылығын қаржыландыру (профицитін пайдалану) 0 теңге.

      > *Ескерту. 2-тармақ жаңа редакцияда – Алматы облысы Ескелді аудандық мәслихатының 12.04.2019 № 47-286 (01.01.2019 бастап қолданысқа енгізіледі) шешімімен.*

3. 2019-2021 жылдарға арналған Бақтыбай ауылдық округінің бюджеті тиісінше осы шешімнің 7, 8, 9-қосымшаларына сәйкес, оның ішінде 2019 жылға келесі көлемдерде бекітілсін:

   1) кірістер 67496 мың теңге, оның ішінде:

      салықтық түсімдер 24996 мың теңге;

      трансферттер түсімі 42500 мың теңге, оның ішінде:

      ағымдағы нысаналы трансферттер 17125 мың теңге;

      субвенциялар 25375 мың теңге;

   2) шығындар 67496 мың теңге;

   3) таза бюджеттік кредиттеу 0 теңге;

   4) қаржы активтерімен операциялар бойынша сальдо 0 теңге;

   5) бюджет тапшылығы (профициті) (-) 0 теңге;

   6) бюджет тапшылығын қаржыландыру (профицитін пайдалану) 0 теңге.

4. 2019-2021 жылдарға арналған Қарабұлақ ауылдық округінің бюджеті тиісінше осы шешімнің 11, 12, 13-қосымшаларына сәйкес, оның ішінде 2019 жылға келесі көлемдерде бекітілсін:

   1) кірістер 164 819 мың теңге, оның ішінде:

      салықтық түсімдер 131 940 мың теңге;

      трансферттердің түсімдері 32 879 мың теңге, оның ішінде:

      ағымдағы нысаналы трансферттер 32 879 мың теңге;

      субвенциялар 0 теңге;

   2) шығындар 164 819 мың теңге;

   3) таза бюджеттік кредиттеу 0 теңге;

   4) қаржы активтерімен операциялар бойынша сальдо 0 теңге;

   5) бюджет тапшылығы (профициті) (-) 0 теңге;

   6) бюджет тапшылығын қаржыландыру (профицитін пайдалану) 0 теңге.

      > *Ескерту. 4-тармақ жаңа редакцияда – Алматы облысы Ескелді аудандық мәслихатының 12.04.2019 № 47-286 (01.01.2019 бастап қолданысқа енгізіледі) шешімімен.*

5. 2019-2021 жылдарға арналған Қаратал ауылдық округінің бюджеті тиісінше осы шешімнің 13, 14, 15-қосымшаларына сәйкес, оның ішінде 2019 жылға келесі көлемдерде бекітілсін:

   1) кірістер 23425 мың теңге, оның ішінде:

      салықтық түсімдер 4367 мың теңге;

      трансферттер түсімі 19058 мың теңге, оның ішінде:

      ағымдағы нысаналы трансферттер 6320 мың теңге;

      субвенциялар 12738 мың теңге;

   2) шығындар 23425 мың теңге;

   3) таза бюджеттік кредиттеу 0 теңге;

   4) қаржы активтерімен операциялар бойынша сальдо 0 теңге;

   5) бюджет тапшылығы (профициті) (-) 0 теңге;

   6) бюджет тапшылығын қаржыландыру (профицитін пайдалану) 0 теңге.

   1) кірістер 60 064 мың теңге, оның ішінде:

      салықтық түсімдер 5 360 мың теңге;

      трансферттердің түсімдері 54 704 мың теңге, оның ішінде:

      ағымдағы нысаналы трансферттер 43 042 мың теңге;

      субвенциялар 11 662 мың теңге;

   2) шығындар 60 064 мың теңге;

   3) таза бюджеттік кредиттеу 0 теңге;

   4) қаржы активтерімен операциялар бойынша сальдо 0 теңге;

   5) бюджет тапшылығы (профициті) (-) 0 теңге;

   6) бюджет тапшылығын қаржыландыру (профицитін пайдалану) 0 теңге.

      > *Ескерту. 6-тармақ жаңа редакцияда – Алматы облысы Ескелді аудандық мәслихатының 12.04.2019 № 47-286 (01.01.2019 бастап қолданысқа енгізіледі) шешімімен.*

7. 2019-2021 жылдарға арналған Сырымбет ауылдық округінің бюджеті тиісінше осы шешімнің 19, 20, 21-қосымшаларына сәйкес, оның ішінде 2019 жылға келесі көлемдерде бекітілсін:

   2) шығындар 53 030 мың теңге;

   3) таза бюджеттік кредиттеу 0 теңге;
