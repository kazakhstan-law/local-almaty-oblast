# Көксу ауданының ауылдық округтерінің 2018-2020 жылдарға арналған бюджеттері туралы

2008 жылғы 4 желтоқсандағы Қазақстан Республикасының Бюджет кодексінің 9-1-бабының 2-тармағына, «Қазақстан Республикасындағы жергілікті мемлекеттік басқару және өзін-өзі басқару туралы» 2001 жылғы 23 қаңтардағы Қазақстан Республикасы Заңының 6-бабының 1-тармағының 1) тармақшасына сәйкес, Көксу ауданы мәслихаты ШЕШІМ ҚАБЫЛДАДЫ:

1. 2018-2020 жылдарға арналған Балпық ауылдық округінің бюджеті тиісінше осы шешімнің 1, 2, 3 - қосымшаларына сәйкес, оның ішінде 2018 жылға келесі көлемдерде бекітілсін:

   1) кірістер 275742 мың теңге, оның ішінде:

      салықтық түсімдер 119480 мың теңге;

      ағымдағы нысаналы трансферттер түсімі 128825 мың теңге;

      субвенциялар 27437 мың теңге;

   2) шығындар 275742 мың теңге;

   3) таза бюджеттік кредит беру 0 мың теңге;

   4) қаржы активтерімен операциялар бойынша сальдо 0 мың теңге;

   5) бюджет тапшылығы (профициті) (-) 0 мың теңге;

   6) бюджет тапшылығын қаржыландыру (профицитін пайдалану) 0 мың теңге.

2. 2018-2020 жылдарға арналған Жарлыөзек ауылдық округінің бюджеті тиісінше осы шешімнің 4, 5, 6 - қосымшаларына сәйкес, оның ішінде 2018 жылға келесі көлемдерде бекітілсін:

   1) кірістер 41431 мың теңге, оның ішінде:

      салықтық түсімдер 4190 мың теңге;

      ағымдағы нысаналы трансферттер түсімі 21442 мың теңге;

      субвенциялар 15799 мың теңге;

   2) шығындар 41431 мың теңге;

   3) таза бюджеттік кредит беру 0 мың теңге;

   4) қаржы активтерімен операциялар бойынша сальдо 0 мың теңге;

   5) бюджет тапшылығы (профициті) (-) 0 мың теңге;

   6) бюджет тапшылығын қаржыландыру (профицитін пайдалану) 0 мың теңге.

3. 2018-2020 жылдарға арналған Лабасы ауылдық округінің бюджеті тиісінше осы шешімнің 7, 8, 9 - қосымшаларына сәйкес, оның ішінде 2018 жылға келесі көлемдерде бекітілсін:

4. 2018-2020 жылдарға арналған Мұқыры ауылдық округінің бюджеті тиісінше осы шешімнің 10, 11, 12 - қосымшаларына сәйкес, оның ішінде 2018 жылға келесі көлемдерде бекітілсін:

9. Осы шешім 2018 жылғы 1 қаңтардан бастап қолданысқа енгізіледі.
