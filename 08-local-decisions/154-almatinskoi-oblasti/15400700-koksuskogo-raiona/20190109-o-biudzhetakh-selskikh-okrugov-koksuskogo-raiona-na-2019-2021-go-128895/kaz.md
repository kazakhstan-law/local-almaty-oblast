# Көксу ауданының ауылдық округтерінің 2019-2021 жылдарға арналған бюджеттері туралы

2008 жылғы 4 желтоқсандағы Қазақстан Республикасының Бюджет кодексінің 9-1-бабының 2-тармағына, «Қазақстан Республикасындағы жергілікті мемлекеттік басқару және өзін-өзі басқару туралы» 2001 жылғы 23 қаңтардағы Қазақстан Республикасы Заңының 6-бабының 1-тармағының 1) тармақшасына сәйкес, Көксу ауданы мәслихаты ШЕШІМ ҚАБЫЛДАДЫ:

1. 2019-2021 жылдарға арналған Балпық ауылдық округінің бюджеті тиісінше осы шешімнің 1, 2, 3-қосымшаларына сәйкес, оның ішінде 2019 жылға келесі көлемдерде бекітілсін:

   1) кірістер 335 111 мың теңге, оның ішінде:

      салықтық түсімдер 105 008 мың теңге;

      салықтық емес түсімдер 0 теңге;

      негізгі капиталды сатудан түсетін түсімдер 0 теңге;

      трансферттер түсімі 230 103 мың теңге, оның ішінде:

      ағымдағы нысаналы трансферттер 184 698 мың теңге;

      субвенциялар 45 405 мың теңге;

   2) шығындар 335 111 мың теңге;

   3) таза бюджеттік кредиттеу 0 теңге,

   4) қаржы активтерімен операциялар бойынша сальдо 0 теңге;

   5) бюджет тапшылығы (профициті) (-) 0 теңге;

   6) бюджет тапшылығын қаржыландыру (профицитін пайдалану) 0 теңге.

2. 2019-2021 жылдарға арналған Жарлыөзек ауылдық округінің бюджеті тиісінше осы шешімнің 4, 5, 6-қосымшаларына сәйкес, оның ішінде 2019 жылға келесі көлемдерде бекітілсін:

      ағымдағы нысаналы трансферттер 70 802 мың теңге;
