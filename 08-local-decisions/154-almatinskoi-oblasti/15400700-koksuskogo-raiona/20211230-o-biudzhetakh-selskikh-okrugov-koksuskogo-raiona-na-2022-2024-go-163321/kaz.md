# Көксу ауданының ауылдық округтерінің 2022-2024 жылдарға арналған бюджеттері туралы

> *Ескерту. 01.01.2022 бастап қолданысқа енгiзiледi - осы шешімінің 12-тармағымен.*

Қазақстан Республикасының Бюджет кодексінің 9-1-бабының 2-тармағына, «Қазақстан Республикасындағы жергілікті мемлекеттік басқару және өзін-өзі басқару туралы» Қазақстан Республикасы Заңының 6-бабының 1-тармағының 1) тармақшасына сәйкес, Көксу ауданы мәслихаты ШЕШТІ:

1. 2022-2024 жылдарға арналған Балпық ауылдық округінің бюджеті тиісінше осы шешімнің 1, 2 және 3-қосымшаларына сәйкес, оның ішінде 2022 жылға келесі көлемдерде бекітілсін:

   1) кірістер 488 864 мың теңге:

      салықтық түсімдер 108 962 мың теңге;

      салықтық емес түсімдер 0 теңге;

      негізгі капиталды сатудан түсетін түсімдер 0 теңге;

      трансферттер түсімі 379 902 мың теңге;

   2) шығындар 488 864 мың теңге;

   3) таза бюджеттік кредиттеу 0 теңге:

      бюджеттік кредиттер 0 теңге;

      бюджеттік кредиттерді өтеу 0 теңге;

   4) қаржы активтерімен операциялар бойынша сальдо 0 теңге:

      қаржы активтерін сатып алу 0 теңге;

      мемлекеттің қаржы активтерін сатудан түсетін түсімдер 0 теңге;

   5) бюджет тапшылығы (профициті) (-) 0 теңге;

   6) бюджет тапшылығын қаржыландыру (профицитін пайдалану) 0 теңге:

      қарыздар түсімі 0 теңге;

      қарыздарды өтеу 0 теңге;
