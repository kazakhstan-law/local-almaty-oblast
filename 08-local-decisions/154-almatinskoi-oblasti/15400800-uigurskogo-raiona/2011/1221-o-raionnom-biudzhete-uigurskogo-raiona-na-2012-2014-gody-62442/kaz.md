# Ұйғыр ауданының 2012-2014 жылдарға арналған бюджеті туралы

РҚАО ескертпесі.

Мәтінде авторлық орфография және пунктуация сақталған.

Қазақстан Республикасы 2008 жылғы 4 желтоқсандағы Бюджет Кодексінің 9-бабының 2-тармағына, Қазақстан Республикасының 2001 жылғы 23 қаңтардағы "Қазақстан Республикасындағы жергілікті мемлекеттік басқару және өзін-өзі басқару туралы" Заңының 6-бабы 1-тармағының 1)-тармақшасына сәйкес, Ұйғыр аудандық мәслихаты ШЕШІМ ҚАБЫЛДАДЫ:

<a id="p1"></a>

1. Ұйғыр ауданының 2012-2014 жылдарға арналған бюджеті 1, 2, және 3 қосымшаларға сәйкес, оның ішінде 2012 жылы мынандай көлемдерде бекітілсін:

   1) Кірістер - 4796916 мың теңге, соның ішінде:

      салықтық түсімдер - 658067 мың теңге;

      меншікке салынатын салықтар - 643109 мың теңге;

      мүлікке салынатын салықтар - 586182 мың теңге;

      салықтық емес түсімдер - 11459 мың теңге;

      негізгі капиталды сатудан түсетін түсімдер - 20661 мың теңге;

      трансферттердің түсімдері - 4053397 мың теңге, соның ішінде:

      ағымдағы нысаналы трансферттер - 831577 мың теңге;

      нысаналы даму трансферттері - 693224 мың теңге;

      субвенциялар - 2528596 мың теңге;

      бюджеттік кредиттерді өтеу - 2365 мың теңге;

      қарыздар түсімі - 46113 мың теңге.

   2) Шығындар - 4826220 мың теңге.

   3) Таза бюджеттік кредиттеу - 77905 мың теңге.

   4) Қаржы активтерімен операциялар бойынша сальдо - 0 теңге.

   5) Бюджет тапшылығы (профициті)- -77905 мың теңге.

   6) Бюджет тапшылығын қаржыландыру (профицитін пайдалану) - 77905 мың теңге.

      > *Ескерту. 1-тармаққа өзгерту енгізілді - Алматы облысы Ұйғыр аудандық мәслихатының 2012.02.17 N 2-1 (2012 жылдың 1 қаңтарынан бастап қолданысқа енгізіледі); 2012.04.13 N 4-4 (2012 жылдың 1 қаңтарынан бастап қолданысқа енгізіледі) Шешімдерімен.*

<a id="p2"></a>

2. Ауданның жергілікті атқарушы органының резерві- 2696 мың теңге сомасында бекітілсін.

<a id="p3"></a>

3. Ауданның 2012 жылға арналған ағымдағы бюджеттік бағдарламалардың тізбесі 4-қосымшаға сәйкес бекітілсін.

<a id="p4"></a>

4. Ауданның 2012 жылға арналған даму бағдарламалардың тізбесі 5-қосымшаға сәйкес бекітілсін.

<a id="p5"></a>

5. Ауданның 2012 жылға арналған аудандық бюджеттің атқарылуы барысында секвестрлеуге жатпайтын бюджеттік бағдарламалардың тізбесі 6-қосымшаға сәйкес бекітілсін.

<a id="p6"></a>

6. Осы шешім 2012 жылдың 1-ші қаңтарынан бастап қолданысқа енеді.
