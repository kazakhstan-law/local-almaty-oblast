# Ұйғыр ауданының ауылдық округтерінің 2018-2020 жылдарға арналған бюджеттері туралы

2008 жылғы 4 желтоқсандағы Қазақстан Республикасы Бюджет кодексінің 9-1-бабының 2-тармағына, «Қазақстан Республикасындағы жергілікті мемлекеттік басқару және өзін-өзі басқару туралы» 2001 жылғы 23 қаңтардағы Қазақстан Республикасы Заңының 6-бабының 1-тармағының1) тармақшасына сәйкес, Ұйғыр аудандық мәслихаты ШЕШІМ ҚАБЫЛДАДЫ:

   1) кірістер 265924 мың теңге, оның ішінде:

      салықтық түсімдер 91802 мың теңге;

      трансферттер түсімі 174122 мың теңге,оның ішінде:

      ағымдағы нысаналы трансферттер 24636 мың теңге;

      субвенциялар 149486 мың теңге;

   2) шығындар 265924 мың теңге;

   3) таза бюджеттік кредиттеу 0 теңге,оның ішінде:

      бюджеттіккредиттерді өтеу 0 теңге;

   4) қаржы активтерімен операциялар бойынша сальдо 0 теңге;

   5) бюджет тапшылығы (профициті)(-) 0 теңге;
