# Ұйғыр ауданының ауылдық округтерінің 2023-2025 жылдарға арналған бюджеттері туралы

> *Ескерту. 01.01.2023 бастап қолданысқа енгiзiледi - осы шешімінің 15-тармағымен.*

Қазақстан Республикасы Бюджет кодексінің 9-1-бабының 2-тармағына, «Қазақстан Республикасындағы жергілікті мемлекеттік басқару және өзін-өзі басқару туралы» Қазақстан Республикасы Заңының 6-бабының 1-тармағының 1) тармақшасына сәйкес, Ұйғыр аудандық мәслихаты ШЕШТІ:

1. 2023-2025 жылдарға арналған Шонжы ауылдық округінің бюджеті тиісінше осы шешімнің 1, 2, 3-қосымшаларына сәйкес, оның ішінде 2023 жылға келесі көлемдерде бекітілсін:

   1) кірістер 199 530 мың теңге, оның ішінде:

      салықтық түсімдер 143 485 мың теңге;

      салықтық емес түсімдер 0 теңге;

      негізгі капиталды сатудан түсетін түсімдер 0 теңге;

      трансферттер түсімдері 56 045 мың теңге;

      бюджеттік кредиттер 0 теңге;

      бюджеттік кредиттерді өтеу 0 теңге;

      қаржылық активтерді сатып алу 0 теңге;

      мемлекеттік қаржы активтерін сатудан түсетін түсімдер 0 теңге;

   5) бюджет тапшылығы (профициті) (-) 0 теңге;

   6) бюджет тапшылығын қаржыландыру (профицитін пайдалану) 0 теңге, оның ішінде:

      қарыздар түсімі 0 теңге;
