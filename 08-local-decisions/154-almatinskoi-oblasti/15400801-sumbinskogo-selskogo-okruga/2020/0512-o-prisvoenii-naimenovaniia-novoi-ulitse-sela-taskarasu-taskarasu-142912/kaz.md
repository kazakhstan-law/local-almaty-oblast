# Тасқарасу ауылдық округінің Тасқарасу ауылындағы жаңа көшеге атау беру туралы

«Қазақстан Республикасының әкімшілік-аумақтық құрылысы туралы» 1993 жылғы 8 желтоқсандағы Қазақстан Республикасы Заңының 14-бабының 4) тармақшасына сәйкес, Тасқарасу ауылдық округінің Тасқарасу ауылы халқының пікірін ескере отырып және Алматы облысының ономастикалық комиссиясының 2019 жылғы 24 желтоқсандағы қорытындысы негізінде, Ұйғыр ауданының Тасқарасу ауылдық округінің әкімі ШЕШІМ ҚАБЫЛДАДЫ:

<a id="p1"></a>

1. Тасқарасу ауылдық округінің Тасқарасу ауылының жаңа көшесіне «Ақкент» атауы берілсін.

<a id="p2"></a>

2. Осы шешімнің орындалуын бақылауды өзіме қалдырамын.

<a id="p3"></a>

3. Осы шешім әділет органдарында мемлекеттік тіркелген күннен бастап күшіне енеді және алғашқы ресми жарияланған күнінен кейін күнтізбелік он күн өткен соң қолданысқа енгізіледі.

**Тасқарасу ауылдық оругінің әкімі**

**К. БАГБАЕВ**
