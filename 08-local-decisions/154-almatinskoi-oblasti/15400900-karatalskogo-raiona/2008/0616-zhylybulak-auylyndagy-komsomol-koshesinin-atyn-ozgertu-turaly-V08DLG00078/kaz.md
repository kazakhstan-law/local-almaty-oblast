# Жылыбұлақ ауылындағы Комсомол көшесінің атын өзгерту туралы

Қазақстан Республикасының "Қазақстан Республикасының әкімшілік-аумақтық құрылысы туралы" Заңының 14-бабының 4-тармақшасынасәйкес Бастөбе ауылдық округі әкімі ШЕШІМ ҚАБЫЛДАДЫ:

<a id="para_1"></a>

1. Жылыбұлақ ауылындағы Комсомол көшесі Шәкәрім ақын атындағы көше болып өзгертілсін.

<a id="para_2"></a>

2. Осы шешімнің орындалуын бақылау ауыл әкімінің орынбасары С. Бейсембаевқа жүктелсін.

<a id="para_3"></a>

3. Осы шешім алғаш ресми жарияланғаннан кейін күнтізбелік он күн өткен соң қолданысқа енгізіледі.

**Әкім:**

**А. Огай**
