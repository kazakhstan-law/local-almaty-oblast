# Қайнар ауылындағы көшеге Қайнар атауын беру туралы

Қазақстан Республикасының "Қазақстан Республикасының әкімшілік-аумақтық құрылысы туралы" Заңының 14-бабының 4-тармақшасына сәйкес Ескелді ауылдық округінің әкімі ШЕШІМ ҚАБЫЛДАДЫ:

<a id="p1"></a>

1. Қайнар ауылындағы көшеге Қайнар атауы берілсін.

<a id="p2"></a>

2. Осы шешімнің орындалуын бақылауды өзіме қалдырамын.

<a id="p3"></a>

3. Осы шешім алғаш ресми жарияланғаннан кейін күнтізбелік он күн өткен соң қолданысқа енгізіледі.

**Әкім:**

**А. Огай**
