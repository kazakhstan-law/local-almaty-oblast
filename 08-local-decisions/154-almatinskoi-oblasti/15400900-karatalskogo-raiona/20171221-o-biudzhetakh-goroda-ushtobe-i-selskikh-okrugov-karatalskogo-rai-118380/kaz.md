# Қаратал ауданының Үштөбе қаласы мен ауылдық округтерінің 2018-2020 жылдарға арналған бюджеттері туралы

2008 жылғы 4 желтоқсандағы Қазақстан Республикасының Бюджет кодексінің 9-1-бабының 2-тармағына, «Қазақстан Республикасындағы жергілікті мемлекеттік басқару және өзін-өзі басқару туралы» 2001 жылғы 23 қаңтардағы Қазақстан Республикасы Заңының 6-бабының 1-тармағының 1) тармақшасына сәйкес, Қаратал аудандық мәслихаты ШЕШІМ ҚАБЫЛДАДЫ:

1. 2018-2020 жылдарға арналған Үштөбе қаласының бюджеті тиісінше осы шешімнің 1, 2 және 3-қосымшаларына сәйкес, оның ішінде 2018 жылға келесі көлемдерде бекітілсін:

   1) кірістер 129918 мың теңге, оның ішінде:

      салықтық түсімдер 43200 мың теңге;

      салықтық емес түсімдер 100 мың теңге;

      трансферттер түсімі 86618 мың теңге;

   2) шығындар 129918 мың теңге;

   3) таза бюджеттік кредиттеу 0 теңге;

   4) қаржы активтерімен операциялар бойынша сальдо 0 теңге;

   5) бюджет тапшылығы (профициті) (-) 0 теңге;

   6) бюджет тапшылығын қаржыландыру (профицитін пайдалану) 0 теңге.

2. 2018-2020 жылдарға арналған Бастөбе ауылдық округінің бюджеті тиісінше осы шешімнің 4, 5 және 6-қосымшаларына сәйкес, оның ішінде 2018 жылға келесі көлемдерде бекітілсін:

   1) кірістер 24779 мың теңге, оның ішінде:

      салықтық түсімдер 5681 мың теңге;

      салықтық емес түсімдер 51 мың теңге;

      трансферттер түсімі 19047 мың теңге;

   2) шығындар 24779 мың теңге;

   3) таза бюджеттік кредиттеу 0 теңге;

   4) қаржы активтерімен операциялар бойынша сальдо 0 теңге;

   5) бюджет тапшылығы (профициті) (-) 0 теңге;

   6) бюджет тапшылығын қаржыландыру (профицитін пайдалану) 0 теңге.

3. 2018-2020 жылдарға арналған Балпық ауылдық округінің бюджеті тиісінше осы шешімнің 7, 8 және 9-қосымшаларына сәйкес, оның ішінде 2018 жылға келесі көлемдерде бекітілсін:

   1) кірістер 19607 мың теңге, оның ішінде:

      салықтық түсімдер 2248 мың теңге;

      салықтық емес түсімдер 22 мың теңге;

      трансферттер түсімі 17337 мың теңге;

   2) шығындар 19607 мың теңге;

   3) таза бюджеттік кредиттеу 0 теңге;

   4) қаржы активтерімен операциялар бойынша сальдо 0 теңге;

   5) бюджет тапшылығы (профициті) (-) 0 теңге;

   6) бюджет тапшылығын қаржыландыру (профицитін пайдалану) 0 теңге.

4. 2018-2020 жылдарға арналған Жолбарыс батыр ауылдық округінің бюджеті тиісінше осы шешімнің 10, 11 және 12-қосымшаларына сәйкес, оның ішінде 2018 жылға келесі көлемдерде бекітілсін:

   1) кірістер 31465 мың теңге, оның ішінде:

      салықтық түсімдер 1450 мың теңге;

      салықтық емес түсімдер 23 мың теңге;

      трансферттер түсімі 29992 мың теңге;

   2) шығындар 31465 мың теңге;

   3) таза бюджеттік кредиттеу 0 теңге;

   4) қаржы активтерімен операциялар бойынша сальдо 0 теңге;

   5) бюджет тапшылығы (профициті) (-) 0 теңге;

   6) бюджет тапшылығын қаржыландыру (профицитін пайдалану) 0 теңге.

5. 2018-2020 жылдарға арналған Ескелді ауылдық округінің бюджеті тиісінше осы шешімнің 13, 14 және 15-қосымшаларына сәйкес, оның ішінде 2018 жылға келесі көлемдерде бекітілсін:

   1) кірістер 20128 мың теңге, оның ішінде:

      салықтық түсімдер 5198 мың теңге;

      салықтық емес түсімдер 66 мың теңге;

      трансферттер түсімі 14864 мың теңге;

   2) шығындар 20128 мың теңге;

   3) таза бюджеттік кредиттеу 0 теңге;

   4) қаржы активтерімен операциялар бойынша сальдо 0 теңге;

   5) бюджет тапшылығы (профициті) (-) 0 теңге;

   6) бюджет тапшылығын қаржыландыру (профицитін пайдалану) 0 теңге.

6. Осы шешімнің орындалуын бақылау Қаратал аудандық мәслихаттың «Жоспарлау, бюджет, шаруашылық қызмет, құрылыс, жерді пайдалану, табиғат қорғау және табиғи қорды ұтымды пайдалану мәселелері жөніндегі» тұрақты комиссиясына жүктелсін.

7. Осы шешім 2018 жылғы 1 қаңтардан бастап қолданысқа енгізіледі.
