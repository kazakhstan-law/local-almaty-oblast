# Қаратал ауданының Үштөбе қаласы мен ауылдық округтерінің 2021-2023 жылдарға арналған бюджеттері туралы

> *Ескерту. 01.01.2021 бастап қолданысқа енгізіледі – осы шешімнің 12-тармағымен.*

2008 жылғы 4 желтоқсандағы Қазақстан Республикасының Бюджет кодексінің 9-1-бабының 2-тармағына, «Қазақстан Республикасындағы жергілікті мемлекеттік басқару және өзін-өзі басқару туралы» 2001 жылғы 23 қаңтардағы Қазақстан Республикасы Заңының 6-бабының 1-тармағының 1) тармақшасына сәйкес, Қаратал аудандық мәслихаты ШЕШІМ ҚАБЫЛДАДЫ:

1. 2021-2023 жылдарға арналған Үштөбе қаласының бюджеті тиісінше осы шешімнің 1, 2 және 3-қосымшаларына сәйкес, оның ішінде 2021 жылға келесі көлемдерде бекітілсін:

   1) кірістер 127 299 мың теңге, оның ішінде:

      салықтық түсімдер 123 978 мың теңге;

      салықтық емес түсімдер 0 теңге;

      негізгі капиталды сатудан түсетін түсімдер 0 теңге;

      трансферттер түсімі 3 321 мың теңге;

   2) шығындар 127 299 мың теңге;

   3) таза бюджеттік кредиттеу 0 теңге, оның ішінде:

      бюджеттік кредиттер 0 теңге;

      бюджеттік кредиттерді өтеу 0 теңге;

   4) қаржы активтерімен операциялар бойынша сальдо 0 теңге, оның ішінде:

      қаржы активтерін сатып алу 0 теңге;

      мемлекеттің қаржы активтерін сатудан түсетін түсімдер 0 теңге;

   5) бюджет тапшылығы (профициті) (-) 0 теңге;

   6) бюджет тапшылығын қаржыландыру (профицитін пайдалану) 0 теңге, оның ішінде:

      қарыздар түсімі 0 теңге;
