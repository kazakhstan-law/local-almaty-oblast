# Еңбекшіқазақ ауданының Есік қаласы мен ауылдық округтерінің 2025-2027 жылдарға арналған бюджеттері туралы

> *Ескерту. 01.01.2025 бастап қолданысқа енгізіледі - осы шешімнің 28-тармағымен.*

Қазақстан Республикасының Бюджет кодексінің 9-1-бабының 2-тармағына, «Қазақстан Республикасындағы жергілікті мемлекеттік басқару және өзін-өзі басқару туралы» Қазақстан Республикасы Заңының 6-бабының 1-тармағының 1) тармақшасына сәйкес, Еңбекшіқазақ аудандық мәслихаты ШЕШТІ:

1. 2025-2027 жылдарға арналған Ават ауылдық округінің бюджеті тиісінше осы шешімінің 1, 2 және 3-қосымшаларына сәйкес, оның ішінде 2025 жылға келесі көлемдерде бекітілсін:

   1) кірістер 170 361 мың теңге, оның ішінде:

      салықтық түсімдер 170 329 мың теңге;

      салықтық емес түсімдер 0 теңге;

      негізгі капиталды сатудан түсетін түсімдер 0 теңге;

      трансферттер түсімі 32 мың теңге, оның ішінде:

      ағымдағы нысаналы трансферттер 0 теңге;

      нысаналы даму трансферттері 0 теңге;

      субвенциялар 0 теңге;

      заңнаманың қабылдауына байланысты ысырапты өтеуге арналған трансферттер 32 мың теңге;

   2) шығындар 195 987 мың теңге;

   3) таза бюджеттік кредиттеу 0 теңге, оның ішінде:

      бюджеттік кредиттер 0 теңге;

      бюджеттік кредиттерді өтеу 0 теңге;

   4) қаржы активтерімен операциялар бойынша сальдо 0 тенге;
