# Белбұлақ ауылдық округіндегі Белбұлақ, Бірлік ауылдарындағы жаңа көшелерге атау беру туралы

«Қазақстан Республикасының әкімшілік-аумақтық құрылысы туралы» 1993 жылғы 8 желтоқсандағы Қазақстан Республикасы Заңының 14-бабының 4) тармақшасына сәйкес және Белбұлақ ауылдық округі халқының пікірін ескере отырып, Алматы облыстық ономастика комиссиясының қорытындысы негізінде Талғар ауданы Белбұлақ ауылдық округінің әкімі ШЕШІМ ҚАБЫЛДАДЫ:

<a id="p1"></a>

1. Белбұлақ ауылдық округінің Белбұлақ ауылының жаңа көшелеріне келесі атаулар берілсін:

   1) Белбұлақ ауылының оңтүстік-шығысында орналасқан бірінші көшеге «Қасым Қайсенов», екінші көшеге «Хиуаз Доспанова»,

<a id="p2"></a>

2. Белбұлақ ауылдық округінің Бірлік ауылының жаңа көшелеріне келесі атаулар берілсін:

   1) Бірлік ауылының оңтүстік-шығысында орналасқан бірінші көшеге «Мәлік Ғабдуллин», екінші көшеге «Сұлтан Баймағамбетов», үшінші көшеге «Нүркен Әбдіров», төртінші көшеге «Төлеген Тоқтаров».

<a id="p3"></a>

3. Осы шешімнің орындалуын бақылауды өзіме қалдырамын.

<a id="p4"></a>

4. Белбұлақ ауылдық округі әкімінің орынбасары Сарғожаев Қазтай Нұрсадықұлына осы шешімді әділет органдарында мемлекеттік тіркелгеннен кейін ресми және мерзімді баспа басылымдарында, сондай-ақ Қазақстан Республикасының Үкіметі белгіленген интернет-ресурста және аудан әкімдігінің интернет-ресурсында жариялау жүктелсін.

<a id="p5"></a>

5. Осы шешім әділет органдарында мемлекеттік тіркелген күннен бастап күшіне енеді және алғашқы ресми жарияланған күнінен кейін күнтізбелік он күн өткен соң қолданысқа енгізіледі.

**Белбұлақ ауылдық округінің әкімі**

**С. Сайранова**
