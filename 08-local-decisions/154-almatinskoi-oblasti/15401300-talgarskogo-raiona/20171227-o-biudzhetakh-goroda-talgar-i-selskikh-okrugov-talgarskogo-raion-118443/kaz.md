# Талғар ауданының Талғар қаласы мен ауылдық округтерінің 2018-2020 жылдарға арналған бюджеттері туралы

2008 жылғы 4 желтоқсандағы Қазақстан Республикасы Бюджет кодексінің 9-1-бабының 2-тармағына, «Қазақстан Республикасындағы жергілікті мемлекеттік басқару және өзін-өзі басқару туралы» 2001 жылғы 23 қаңтардағы Қазақстан Республикасы Заңының 6-бабы 1-тармағының 1) тармақшасына сәйкес, Талғар аудандық мәслихаты ШЕШІМ ҚАБЫЛДАДЫ:

1. 2018-2020 жылдарға арналған Талғар қаласының бюджеті тиісінше осы шешімнің 1, 2, 3-қосымшаларына сәйкес, оның ішінде 2018 жылға келесі көлемдерде бекітілсін:

   1) кірістер 714 877 мың теңге, оның ішінде:

      салықтық түсімдер 714 877 мың теңге;

      салықтық емес түсімдер 0 мың теңге;

      трансферттер түсімі 0 мың теңге, оның ішінде:

      ағымдағы нысаналы трансферттер 0 мың теңге;

      нысаналы даму трансферттері 0 мың теңге;

      бюджеттік кредиттер 0 мың теңге;

   5) бюджет тапшылығы (профициті) (-) 0 мың теңге;
