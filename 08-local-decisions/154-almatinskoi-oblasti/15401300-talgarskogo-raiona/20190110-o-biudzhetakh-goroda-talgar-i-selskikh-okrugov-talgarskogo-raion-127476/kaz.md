# Талғар ауданының Талғар қаласы мен ауылдық округтерінің 2019-2021 жылдарға арналған бюджеттері туралы

2008 жылғы 4 желтоқсандағы Қазақстан Республикасы Бюджет кодексінің 9-1-бабының 2-тармағына, «Қазақстан Республикасындағы жергілікті мемлекеттік басқару және өзін-өзі басқару туралы» 2001 жылғы 23 қаңтардағы Қазақстан Республикасы Заңының 6-бабының 1-тармағының 1) тармақшасына сәйкес, Талғар аудандық мәслихаты ШЕШІМ ҚАБЫЛДАДЫ:

1. 2019-2021 жылдарға арналған Талғар қаласының бюджеті тиісінше осы шешімнің 1, 2, 3-қосымшаларына сәйкес, оның ішінде 2019 жылға келесі көлемдерде бекітілсін:

   1) кірістер 699 048 мың теңге, оның ішінде:

      салықтық түсімдер 649 507 мың теңге;

      салықтық емес түсімдер 0 теңге;

      трансферттер түсімі 49 541 мың теңге, оның ішінде:

      ағымдағы нысаналы трансферттер 49 541 мың теңге;

      нысаналы даму трансферттері 0 теңге;

   2) шығындар 706 012 мың теңге;

   3) таза бюджеттік кредиттеу 0 теңге, оның ішінде:

      бюджеттік кредиттер 0 теңге;

      бюджеттік кредиттерді өтеу 0 теңге;

   4) қаржы активтерімен операциялар бойынша сальдо 0 теңге;
