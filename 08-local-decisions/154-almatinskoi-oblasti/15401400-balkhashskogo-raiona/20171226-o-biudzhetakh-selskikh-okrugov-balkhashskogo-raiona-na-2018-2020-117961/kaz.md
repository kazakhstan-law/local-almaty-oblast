# Балқаш ауданының ауылдық округтерінің 2018-2020 жылдарға арналған бюджеттері туралы

2008 жылғы 4 желтоқсандағы Қазақстан Республикасының Бюджет кодексінің 9-1 бабының 2-тармағына және «Қазақстан Республикасындағы жергілікті мемлекеттік басқару және өзін-өзі басқару туралы» 2001 жылғы 23 қаңтардағы Қазақстан Республикасы Заңының 6-бабы 1-тармағының 1) тармақшасына сәйкес, Балқаш аудандық мәслихаты ШЕШІМ ҚАБЫЛДАДЫ:

1. Балқаш ауданы Ақдала ауылдық округінің 2018-2020 жылдарға арналған бюджеті тиісінше осы шешімнің 1, 2 және 3-қосымшаларына сәйкес, оның ішінде 2018 жылға келесі көлемдерде бекітілсін:

   1) кірістер 16 069 мың теңге, оның ішінде:

      салықтық түсімдер 4 918 мың теңге;

      салықтық емес түсімдер 0 теңге;

      негізгі капиталды сатудан түсетін түсімдер 0 теңге;

      трансферттер түсімі 11 151 мың теңге, оның ішінде:

      ағымдағы нысаналы трансферттер 0 теңге;

      нысаналы даму трансферттері 0 теңге;

      субвенциялар 11 151 мың теңге;

   2) шығындар 16 069 мың теңге;

   3) таза бюджеттік кредиттеу 0 теңге, оның ішінде:

      бюджеттік кредиттер 0 теңге;

      бюджеттік кредиттерді өтеу 0 теңге;

   4) қаржылық активтерімен операциялар бойынша сальдо 0 теңге;

   5) бюджет тапшылығы (профициті) (-) 0 теңге;

   6) бюджет тапшылығын қаржыландыру (профицитін пайдалану) 0 теңге.
