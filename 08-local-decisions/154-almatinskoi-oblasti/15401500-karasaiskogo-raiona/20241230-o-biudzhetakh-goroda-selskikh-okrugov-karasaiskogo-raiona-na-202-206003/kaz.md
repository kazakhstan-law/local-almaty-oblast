# Қарасай ауданының қала, ауылдық округтерінің 2025-2027 жылдарға арналған бюджеттері туралы

> *Ескерту. 01.01.2025 бастап қолданысқа енгізіледі - осы шешімнің 13-тармағымен.*

Қазақстан Республикасының Бюджет кодексінің 9-1-бабының 2-тармағына, «Қазақстан Республикасындағы жергілікті мемлекеттік басқару және өзін-өзі басқару туралы» Қазақстан Республикасы Заңының 6-бабының 1-тармағының 1) тармақшасына сәйкес, Қарасай аудандық мәслихаты ШЕШТІ:

1. Қарасай ауданы Қаскелең қаласының 2025-2027 жылдарға арналған бюджеті тиісінше осы шешімнің 1, 2, 3-қосымшаларына сәйкес, оның ішінде 2025 жылға келесі көлемдерде бекітілсін:

   1) кірістер 3 646 080 мың теңге, оның ішінде:

      салықтық түсімдер 3 230 683 мың теңге;

      салықтық емес түсімдер 0 теңге;

      негізгі капиталды сатудан түсетін түсімдер 0 теңге;

      трансферттер түсімі 415 397 мың теңге;

   2) шығындар 3 646 080 мың теңге;

   3) таза бюджеттік кредиттеу 0 теңге:

      бюджеттік кредиттер 0 теңге;

      бюджеттік кредиттерді өтеу 0 теңге;

   4) қаржы активтерімен операциялар бойынша сальдо 0 теңге;

   5) бюджет тапшылығы (профициті) (-) 0 теңге;
