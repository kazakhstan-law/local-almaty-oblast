# Междуреченск ауылдық округі, Екпінді ауылындағы Школьная көшесін Майкот Алгазиевтің атына ауыстыру туралы

Қазақстан Республикасының «Қазақстан Республикасындағы әкімшілік-аумақтық құрылысы туралы» Заңының 14-бабының 4-тармағын басшылыққа ала отырып, Междуреченск ауылдық округ әкімі ШЕШІМ ҚАБЫЛДАДЫ:

<a id="para_1"></a>

1. Междуреченск ауылыдык округі, Екпінді ауылындағы Школьная көшесі Майкот Алгазиевтің атына ауыстырылсын.

<a id="para_2"></a>

2. Осы шешімнің орындалуына бақылауды өзіме қалдырамын.

<a id="para_3"></a>

3. Осы шешім алғаш ресми жарияланғаннан кейін күнтізбелік он күннен соң қолданысқа енгізіледі.

**Междуреченск ауылдық округ әкімі**

**Қ. Базарбаев**
