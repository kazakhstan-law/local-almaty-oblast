# Междуреченск ауылдық округінде жаңа бөлінген көшелерге атау беру туралы

Қазақстан Республикасының «Қазақстан Республикасындағы әкімшілік-аумақтық құрылысы туралы» Заңының 14-бабының 4-тармағын басшылыққа ала отырып, округ әкімі ШЕШІМ ҚАБЫЛДАДЫ:

<a id="p1"></a>

1. Междуреченск ауылдық округінде жаңа көшелерге Қазақстан Республикасына айрыкша еңбегі сінген және оның тарихына, әдебиетіне елеулі еңбек үлесің қосқан мәдениет қайраткерлерінің төмендегі есімдері берілсін:

   Междуреченск ауылы бойынша:

   ұзындығы 450 метр көшеге Ақан сері

   ұзындығы 450 метр көшеге Нұрғиса Тлендиев

   ұзындығы 450 метр көшеге Алпамыс батыр

   Екпінді ауылы бойынша:

   ұзындығы 700 метр көшеге Новая

   ұзындығы 300 метр көшеге Мәншүк Маметова

   ұзындығы 700 метр көшеге Бикен Римова

   ұзындығы 500 метр көшеге Бұқар жырау

   ұзындығы 700 метр көшеге Наурызбай батыр

   ұзындығы 700 метр көшеге Бөлек батыр

   ұзындығы 700 метр көшеге Қобланды батыр

   ұзындығы 700 метр көшеге Шоқан Уәлиханов

   ұзындығы 700 метр көшеге Мұхтар Әуезов

   ұзындығы 700 метр көшеге Райымбек батыр

   ұзындығы 700 метр көшеге Ескелді би

   Жауғашты ауылы бойынша:

   ұзындығы 450 метр көшеге Жауғашты батыр

   ұзындығы 450 метр көшеге Бауыржан Момышұлы

<a id="p2"></a>

2. Осы шешімнің орындалуын бақылауды өзіме қалдырамын.

<a id="p3"></a>

3. Осы шешім алғаш ресми жарияланғаннан кейін күнтізбелік он күннен соң қолданысқа енгізіледі.

**Междуреченск ауылдық округ әкімі**

**Қ. Базарбаев**
