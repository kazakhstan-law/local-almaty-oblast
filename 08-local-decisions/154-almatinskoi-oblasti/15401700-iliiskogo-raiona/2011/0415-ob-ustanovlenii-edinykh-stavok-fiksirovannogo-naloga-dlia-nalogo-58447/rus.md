# Об установлении единых ставок фиксированного налога для налогоплательщиков на 2011 год

Согласно статьи 422 Кодекса Республики Казахстан "О налогах и других обязательных платежах в бюджет" (Налоговый кодекс), Илийский районный маслихат РЕШИЛ:

<a id="p1"></a>

1. Единые ставки фиксированного налога на 2011 год для всех налогоплательщиков, осуществляющих деятельность на территории района установить согласно приложения.

<a id="p2"></a>

2. Контроль за исполнением данного решения возложить на постоянную комиссию по вопросам бюджета, социально экономического развития, транспорта, связи, промышленности, сельского хозяйства и предпринимательства (Карпов Дмитрий Павлович).

<a id="p3"></a>

3. Настоящее решение вступает в силу по истечении десяти календарных дней после официального опубликования.

*Председатель сессии Б. Сулейменова*
