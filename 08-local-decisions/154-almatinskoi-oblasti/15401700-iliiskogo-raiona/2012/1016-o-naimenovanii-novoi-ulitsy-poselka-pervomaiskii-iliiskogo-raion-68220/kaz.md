# Іле ауданы Первомай кентінің жаңа көшесіне ат қою туралы

> РҚАО ескертпесі.

> Мәтінде авторлық орфография және пунктуация сақталған.

"Қазақстан Республикасының әкімшілік-аумақтық құрылысы туралы" Қазақстан Республикасының 1993 жылғы 8 желтоқсандағы Заңының 14–бабының 4) тармақшасына сәйкес, аудандық ономастика кеңесінің келісімімен және ауыл тұрғындарының пікірін ескере отырып Іле ауданы Первомай кентінің әкімі ШЕШІМ ЕТЕДІ:

<a id="p1"></a>

1. Іле ауданы Первомай кентінің батысында орналасқан жаңа көшеге "Бережинский Алексей Федорович" аты қойылсын.

<a id="p2"></a>

2. Осы шешімнің орындалуын бақылау жасау Первомай кенті әкімінің орынбасары Таңатар Айнұр Таңатарқызына жүктелсін.

<a id="p3"></a>

3. Осы шешім әділет органдарында мемлекеттік тіркелген күннен бастап күшіне енеді және алғаш ресми жарияланғаннан кейін күнтізбелік он күн өткен соң қолданысқа енгізіледі.

**Первомай кенттік округ әкімі**

**А. Советханов**
