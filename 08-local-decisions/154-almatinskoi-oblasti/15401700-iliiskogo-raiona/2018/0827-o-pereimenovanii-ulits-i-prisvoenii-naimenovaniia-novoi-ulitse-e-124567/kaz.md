# Энергетический ауылдық округінің көшелерін қайта атау және жаңа көшесіне атау беру туралы

«Қазақстан Республикасының әкімшілік-аумақтық құрылысы туралы» 1993 жылғы 8 желтоқсандағы Қазақстан Республикасы Заңының 14-бабының 4) тармақшасына сәйкес, Энергетический ауылдық округі халқының пікірін ескере отырып және 2018 жылғы 26 наурыздағы Алматы облыстық ономастикалық комиссиясының қорытындысы негізінде, Іле ауданы, Энергетический ауылдық округінің әкімі ШЕШІМ ҚАБЫЛДАДЫ:

<a id="p1"></a>

1. Энергетический ауылдық округінің келесі көшелері қайта аталсын:

   1) Өтеген батыр кентінің шығысында орналасқан «Калинин» көшесі «Жерұйық» көшесіне;

   2) Покровка кентінің шығысында орналасқан «Космонавтов» көшесі «Байқоңыр» көшесіне, «Луговая» көшесі «Достық» көшесіне, «Мир» көшесі «Бейбітшілік» көшесіне, «Молодежная» көшесі «Бәйтерек» көшесіне, «Садовая» көшесі «Егемендік» көшесіне, «Центральная» көшесі «Шұғыла» көшесіне;

   3) «Арман» ықшам ауданының шығысында орналасқан «70 лет ВЛКСМ» көшесі «Көктөбе» көшесіне, «Советская» көшесі «Бірлік» көшесіне, «Стройтельная» көшесі «Алтын орда» көшесіне.

<a id="p2"></a>

2. Энергетический ауылдық округінің «Гүлдер» ықшам ауданының шығысында орналасқан жаңа көшесіне «Манас» атауы берілсін.

<a id="p3"></a>

3. Осы шешімнің орындалуын бақылауды өзіме қалдырамын.

<a id="p4"></a>

4. Осы шешім әділет органдарында мемлекеттік тіркелген күннен бастап күшіне енеді және алғашқы ресми жарияланған күнінен кейін күнтізбелік он күн өткен соң қолданысқа енгізіледі.

**Энергетический ауылдық округі әкімі**

**С. Закиржанов**
