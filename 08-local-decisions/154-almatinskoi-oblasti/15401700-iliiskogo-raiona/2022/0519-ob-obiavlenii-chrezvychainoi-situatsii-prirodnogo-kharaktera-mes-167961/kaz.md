# Табиғи сипатындағы жергілікті ауқымдағы төтенше жағдайды жариялау туралы

Қазақстан Республикасының «Қазақстан Республикасындағы жергілікті басқару және өзін-өзі басқару туралы» Заңының 33-бабы 1-тармағының 13) тармақшасына, Қазақстан Республикасының «Азаматтық қорғау туралы» Заңының 48-бабына және 50-бабы 2-тармағының 2) тармақшасына, Қазақстан Республикасы Үкіметінің 2014 жылғы 2 шілдедегі №756 «Табиғи және техногендік сипаттағы төтенше жағдайлардың сыныптамасын белгілеу туралы» қаулысына сәйкес ШЕШТІМ:

<a id="p1"></a>

1. Іле ауданы аумағында жергілікті ауқымдағы табиғи сипаттағы төтенше жағдай жариялансын.

<a id="p2"></a>

2. Табиғи сипаттағы төтенше жағдайды жою басшысы болып Іле ауданы әкімінің орынбасары М.М.Касенов тағайындалсын.

<a id="p3"></a>

3. Осы шешімнің орындалуын бақылау Іле ауданы әкімінің жетекшілік ететін орынбасарына жүктелсін.

<a id="p4"></a>

4. Осы шешім оның алғашқы ресми жарияланған күнінен бастап қолданысқа енгізіледі.

   **Аудан әкімі**

   **Б. Карасаев**
