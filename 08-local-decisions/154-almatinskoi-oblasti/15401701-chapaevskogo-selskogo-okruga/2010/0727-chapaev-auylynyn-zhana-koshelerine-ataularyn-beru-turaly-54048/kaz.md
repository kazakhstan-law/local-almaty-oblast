# Чапаев ауылының жаңа көшелеріне атауларын беру туралы

«Қазақстан Республикасының «Қазақстан Республикасының әкімшілік аумақтық құрылымы туралы» Заңының 14-бабы 4-тармақшасына, Чапаев ауылының әкімі ШЕШІМ ҚАБЫЛДАДЫ:

<a id="p1"></a>

1. Чапаев ауылындағы ұзындығы – 500 м жаңа көшеге Самұрық атауы берілсі.

<a id="p2"></a>

2. Чапаев ауылындағы ұзындығы – 300 м жаңа көшеге Болашақ атауы берілсін.

<a id="p3"></a>

3. Чапаев ауылындағы ұзындығы – 400 м жаңа көшеге Алтын дән атауы берілсін.

<a id="p4"></a>

4. Осы шешімнің орындалуын бақылауды өзіме қалдырамын.

<a id="p5"></a>

5. Осы шешім алғаш ресми жарияланғаннан кейін күнтізбелік он күннен соң қолданысқа енгізіледі.

**Чапаев ауылының әкімі**

**Д.Т. Конурбаев**
