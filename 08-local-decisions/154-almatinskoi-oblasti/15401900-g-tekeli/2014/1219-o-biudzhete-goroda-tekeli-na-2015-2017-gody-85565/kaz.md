# Текелі қаласының 2015-2017 жылдарға арналған бюджеті туралы

> РҚАО ескертпесі.

> Құжаттың мәтінінде түпнұсқасының пунктуациясы мен орфографиясы сақталған.

2008 жылғы 4 желтоқсандағы Қазақстан Республикасының Бюджет кодексінің 9-бабының 2-тармағына, «Қазақстан Республикасындағы жергілікті мемлекеттік басқару және өзін-өзі басқару туралы» 2001 жылғы 23 қаңтардағы Қазақстан Республикасы Заңының 6-бабы 1-тармағының 1) тармақшасына сәйкес, Текелі қалалық мәслихаты ШЕШІМ ҚАБЫЛДАДЫ:

<a id="p1"></a>

1. 2015-2017 жылдарға арналған қала бюджеті тиісінше 1, 2 және 3 қосымшаларға сәйкес, соның ішінде 2015 жылға келесі көлемдерде бекітілсін:

   1\) кірістер 3115573 мың теңге, соның ішінде:

   салықтық түсімдер 109479 мың теңге;

   салықтық емес түсімдер 7409 мың теңге;

   негізгі капиталды сатудан түсетін түсімдер 15664 мың теңге;

   трансферттер түсімі 2983021 мың теңге, соның ішінде:

   ағымдағы нысаналы трансферттер 789758 мың теңге;

   нысаналы даму трансферттері 1106695 мың теңге;

   субвенциялар 1086568 мың теңге;

   2\) шығындар 3142801 мың теңге;

   3)таза бюджеттік кредиттеу 114564 мың теңге, соның ішінде:

   бюджеттік кредиттер 114564 мың теңге;

   бюджеттік кредиттерді өтеу 0 теңге;

   4\) қаржы активтерімен операциялар бойынша сальдо 0 теңге;

   5\) бюджет тапшылығы (профицитi) (-) 141792 мың теңге;

   6\) бюджет тапшылығын қаржыландыру (профицитiн пайдалану) 141792 мың теңге.

   > *Ескерту. 1-тармақ жаңа редакцияда - Алматы облысы Текелі қалалық мәслихатының 09.02.2015 № 37-241 (01.01.2015 бастап қолданысқа енгізіледі) шешімімен.*

<a id="p2"></a>

2. 2015 жылға Текелі қаласының жергілікті атқарушы органының резерві 2253 мың теңге сомасында бекітілсін.

<a id="p3"></a>

3. 2015 жылға арналған қалалық бюджетті атқару процесінде секвестрлеуге жатпайтын қалалық бюджеттік бағдарламалардың тізбесі 4 қосымшаға сәйкес бекітілсін.

<a id="p4"></a>

4. Осы шешімнің орындалуын бақылау Текелі қалалық мәслихатының «Бюджет және экономика мәселесі бойынша» тұрақты комиссиясына жүктелсін.

<a id="p5"></a>

5. Осы шешім 2015 жылдың 1 қаңтарынан бастап қолданысқа енгізіледі.
