# Об утверждении Плана по управлению пастбищамии их использованию по городу Капшагай на 2018-2019 годы

В соответствии с подпунктом 1) статьи 8 Закона Республики Казахстан от 20 февраля 2017 года «О пастбищах», Капшагайский городской маслихат РЕШИЛ:

<a id="p1"></a>

1. Утвердить План по управлению пастбищами и их использованию по городу Капшагай на 2018-2019 годы согласно приложениям 1, 2, 3, 4, 5, 6, 7 к настоящему решению.

<a id="p2"></a>

2. Контроль за исполнением настоящего решения возложить на постоянную комиссию городского маслихата «По развитию сельского и жилищно-коммунального хозяйства, эффективному использованию природных ресурсов».

<a id="p3"></a>

3. Настоящее решение вступает в силу со дня государственной регистрации в органах юстиции и вводится в действие по истечении десяти календарных дней после дня его первого официального опубликования.
