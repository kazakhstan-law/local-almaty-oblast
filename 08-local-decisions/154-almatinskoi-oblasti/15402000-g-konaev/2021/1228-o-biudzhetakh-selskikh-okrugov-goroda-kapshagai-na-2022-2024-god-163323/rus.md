> *Сноска. Вводится в действие с 01.01.2022 в соответствии с пунктом 3 настоящего решения.*

      бюджетные кредиты 0 тенге;

      погашение бюджетных кредитов 0 тенге;

   4) сальдо по операциям с финансовыми активами 0 тенге;

   5) дефицит (профицит) бюджета 0 тенге;

   6) финансирование дефицита (использование профицита) бюджета 0 тенге, в том числе:

      поступление займов 0 тенге;

      погашение займов 0 тенге;

      используемые остатки бюджетных средств 0 тенге.

2. Утвердить бюджет Шенгельдинского сельского округа на 2022-2024 годы, согласно приложениям 4, 5, 6 к настоящему решению соответственно, в том числе на 2022 год в следующих объемах:

   1) доходы 125 707 тысяч тенге, в том числе:

      налоговые поступления 23 490 тысяч тенге;

      бюджетные кредиты 0 тенге;

      погашение бюджетных кредитов 0 тенге;

      поступление займов 0 тенге;
