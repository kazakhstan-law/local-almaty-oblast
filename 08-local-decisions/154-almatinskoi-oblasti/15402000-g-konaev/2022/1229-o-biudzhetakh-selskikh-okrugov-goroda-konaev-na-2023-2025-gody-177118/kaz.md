# Қонаев қаласы ауылдық округтерінің 2023-2025 жылдарға арналған бюджеттері туралы

> *Ескерту. 01.01.2023 бастап қолданысқа енгiзiледi - осы шешімінің 3-тармағымен.*

2008 жылғы 4 желтоқсандағы Қазақстан Республикасының Бюджет кодексінің 9-1-бабының 2-тармағына, «Қазақстан Республикасындағы жергілікті мемлекеттік басқару және өзін-өзі басқару туралы» 2001 жылғы 23 қаңтардағы Қазақстан Республикасы Заңының 6-бабының 1-тармағының 1) тармақшасына сәйкес, Қонаев қаласының мәслихаты ШЕШІМ ҚАБЫЛДАДЫ:

1. 2023-2025 жылдарға арналған Заречный ауылдық округінің бюджеті тиісінше осы шешімнің 1, 2, 3-қосымшаларына сәйкес, оның ішінде 2023 жылға келесі көлемдерде бекітілсін:

   1) кірістер 187 103 мың теңге, оның ішінде:

      салықтық түсімдер 16 550 мың теңге;

      салықтық емес түсімдер 0 теңге;

      негізгі капиталды сатудан түсетін түсімдер 0 теңге;

      трансферттер түсімі 170 553 мың теңге;

   2) шығындар 190 523 мың теңге;

   3) таза бюджеттік кредиттеу 0 теңге, оның ішінде:

      бюджеттік кредиттер 0 теңге;

      бюджеттік кредиттерді өтеу 0 теңге;

   4) қаржы активтерімен операциялар бойынша сальдо 0 теңге;

   5) бюджет тапшылығы (профициті) (-) 3 420 мың теңге;

   6) бюджет тапшылығын қаржыландыру (профицитін пайдалану) 3 420 мың теңге, оның ішінде:

      қарыздар түсімі 0 теңге;

      қарыздарды өтеу 0 теңге;

      бюджет қаражатының пайдаланылатын қалдықтары 3 420 мың теңге.

      > *Ескерту. 1-тармақ жаңа редакцияда – Алматы облысы Қонаев қалалық мәслихатының 10.11.2023 № 14-44 (01.01.2023 бастап қолданысқа енгізіледі); 25.12.2023 № 15-48 (01.01.2023 бастап қолданысқа енгізіледі) шешімдерімен.*

2. 2023-2025 жылдарға арналған Шеңгелді ауылдық округінің бюджеті тиісінше осы шешімнің 4, 5, 6-қосымшаларына сәйкес, оның ішінде 2023 жылға келесі көлемдерде бекітілсін:

   1) кірістер 151 507 мың теңге, оның ішінде:

      салықтық түсімдер 22 290 мың теңге;

      салықтық емес түсімдер 0 теңге;

      негізгі капиталды сатудан түсетін түсімдер 0 теңге;

      трансферттер түсімі 129 217 мың теңге;

   2) шығындар 153 285 мың теңге;

   3) таза бюджеттік кредиттеу 0 теңге, оның ішінде:

      бюджеттік кредиттер 0 теңге;

      бюджеттік кредиттерді өтеу 0 теңге;

   4) қаржы активтерімен операциялар бойынша сальдо 0 теңге;

   5) бюджет тапшылығы (профициті) (-) 1 778 мың теңге;

   6) бюджет тапшылығын қаржыландыру (профицитін пайдалану) 1 778 мың теңге, оның ішінде:

      қарыздар түсімі 0 теңге;

      қарыздарды өтеу 0 теңге;

      бюджет қаражатының пайдаланылатын қалдықтары 1 778 мың теңге.

      > *Ескерту. 2-тармақ жаңа редакцияда – Алматы облысы Қонаев қалалық мәслихатының 10.11.2023 № 14-44 (01.01.2023 бастап қолданысқа енгізіледі); 25.12.2023 № 15-48 (01.01.2023 бастап қолданысқа енгізіледі) шешімдерімен.*

3. Осы шешім 2023 жылдың 1 қаңтарынан қолданысқа енгізіледі.
