# Қонаев қаласының ауылдық округтерінің 2024-2026 жылдарға арналған бюджеттері туралы

> *Ескерту. 01.01.2024 бастап қолданысқа енгізіледі - осы шешімнің 3-тармағымен.*

Қазақстан Республикасының Бюджет кодексінің 9-1-бабының 2-тармағына, «Қазақстан Республикасындағы жергілікті мемлекеттік басқару және өзін-өзі басқару туралы» Қазақстан Республикасы Заңының 6-бабының 1-тармағының 1) тармақшасына сәйкес, Қонаев қаласының мәслихаты ШЕШІМ ҚАБЫЛДАДЫ:

1. 2024-2026 жылдарға арналған Заречный ауылдық округінің бюджеті тиісінше осы шешімнің 1, 2, 3-қосымшаларына сәйкес, оның ішінде 2024 жылға келесі көлемдерде бекітілсін:

   1) кірістер 28 612 мың теңге, оның ішінде:

      салықтық түсімдер 10 185 мың теңге;

      салықтық емес түсімдер 0 теңге;

      негізгі капиталды сатудан түсетін түсімдер 0 теңге;

      трансферттер түсімі 18 427 мың теңге;

   2) шығындар 29 843 мың теңге;

   3) таза бюджеттік кредиттеу 0 теңге, оның ішінде:

      бюджеттік кредиттер 0 теңге;

      бюджеттік кредиттерді өтеу 0 теңге;

   4) қаржы активтерімен операциялар бойынша сальдо 0 теңге, оның ішінде:

      қаржы активтерін сатып алу 0 теңге;

      мемлекеттің қаржы активтерін сатудан түсетін түсімдер 0 теңге;

   5) бюджет тапшылығы (профициті) (-) 1 231 мың теңге;

   6) бюджет тапшылығын қаржыландыру (профицитін пайдалану) 1 231 мың теңге, оның ішінде:

      қарыздар түсімі 0 теңге;

      қарыздарды өтеу 0 теңге;

      бюджет қаражатының пайдаланылатын қалдықтары 1 231 мың теңге.

      > *Ескерту. 1-тармақ жаңа редакцияда – Алматы облысы Қонаев қалалық мәслихатының 24.05.2024 № 28-93 (01.01.2024 бастап қолданысқа енгізіледі); 19.07.2024 № 29-100 (01.01.2024 бастап қолданысқа енгізіледі) шешімдерімен.*

2. 2024-2026 жылдарға арналған Шеңгелді ауылдық округінің бюджеті тиісінше осы шешімнің 4, 5, 6-қосымшаларына сәйкес, оның ішінде 2024 жылға келесі көлемдерде бекітілсін:

   1) кірістер 317 108 мың теңге, оның ішінде:

      салықтық түсімдер 47 326 мың теңге;

      салықтық емес түсімдер 0 теңге;

      негізгі капиталды сатудан түсетін түсімдер 0 теңге;

      трансферттер түсімі 269 782 мың теңге;

   2) шығындар 322 713 мың теңге;

   3) таза бюджеттік кредиттеу 0 теңге, оның ішінде:

      бюджеттік кредиттер 0 теңге;

      бюджеттік кредиттерді өтеу 0 теңге;

   4) қаржы активтерімен операциялар бойынша сальдо 0 теңге, оның ішінде:

      қаржы активтерін сатып алу 0 теңге;

      мемлекеттің қаржы активтерін сатудан түсетін түсімдер 0 теңге;

   5) бюджет тапшылығы (профициті) (-) 5 605 мың теңге;

   6) бюджет тапшылығын қаржыландыру (профицитін пайдалану) 5 605 мың теңге, оның ішінде:

      қарыздар түсімі 0 теңге;

      қарыздарды өтеу 0 теңге;

      бюджет қаражатының пайдаланылатын қалдықтары 5 605 мың теңге.

      > *Ескерту. 2-тармақ жаңа редакцияда – Алматы облысы Қонаев қалалық мәслихатының 24.05.2024 № 28-93 (01.01.2024 бастап қолданысқа енгізіледі) шешімімен.*

3. Осы шешім 2024 жылдың 1 қаңтарынан қолданысқа енгізіледі.

   **Қонаев қаласы мәслихатының төрағасы**

   **Қ. Ахметтаев**

> *Қонаев қаласы мәслихатының 2023 жылғы 29 желтоқсандағы № 17-52 шешіміне 1-қосымша*
