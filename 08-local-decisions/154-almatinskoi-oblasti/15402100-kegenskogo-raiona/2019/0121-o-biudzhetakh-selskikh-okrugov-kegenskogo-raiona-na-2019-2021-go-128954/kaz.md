# «Кеген ауданының ауылдық округтерінің 2019-2021 жылдарға арналған бюджеттері туралы»

2008 жылғы 4 желтоқсандағы Қазақстан Республикасының Бюджет кодексінің 9-1-бабының 2-тармағына, «Қазақстан Республикасындағы жергілікті мемлекеттік басқару және өзін-өзі басқару туралы» 2001 жылғы 23 қаңтардағы Қазақстан Республикасы Заңының 6-бабының 1-тармағының 1) тармақшасына сәйкес, Кеген аудандық мәслихаты ШЕШІМ ҚАБЫЛДАДЫ:

1. 2019-2021 жылдарға арналған Кеген ауылдық округінің бюджеті тиісінше осы шешімнің 1, 2, 3-қосымшаларына сәйкес, оның ішінде 2019 жылға келесі көлемдерде бекітілсін:

   1) кірістер 171674 мың теңге, оның ішінде:

      салықтық түсімдер 24863 мың теңге;

      трансферттер түсімі 146811 мың теңге, оның ішінде:

      ағымдағы нысаналы трансферттер 96973 мың теңге;

      субвенциялар 49838 мың теңге;

   2) шығындар 171674 мың теңге;

   3) таза бюджеттік кредиттеу 0 теңге;

   4) қаржы активтерімен операциялар бойынша сальдо 0 теңге;

   5) бюджет тапшылығы (профициті) (-) 0 теңге;

   6) бюджет тапшылығын қаржыландыру (профицитін пайдалану) 0 теңге.

2. 2019-2021 жылдарға арналған Жалаңаш ауылдық округінің бюджеті тиісінше осы шешімнің 4, 5, 6-қосымшаларына сәйкес, оның ішінде 2019 жылға келесі көлемдерде бекітілсін:

   1) кірістер 46175 мың теңге, оның ішінде:

      салықтық түсімдер 11518 мың теңге;

      трансферттер түсімі 34657 мың теңге, оның ішінде:

      ағымдағы нысаналы трансферттер 24107 мың теңге;

      субвенциялар 10550 мың теңге;

   2) шығындар 46175 мың теңге;

   3) таза бюджеттік кредиттеу 0 теңге;

   4) қаржы активтерімен операциялар бойынша сальдо 0 теңге;

   5) бюджет тапшылығы (профициті) (-) 0 теңге;

   6) бюджет тапшылығын қаржыландыру (профицитін пайдалану) 0 теңге.

3. 2019-2021 жылдарға арналған Жылысай ауылдық округінің бюджеті тиісінше осы шешімнің 7, 8, 9-қосымшаларына сәйкес, оның ішінде 2019 жылға келесі көлемдерде бекітілсін:

   1) кірістер 21016 мың теңге, оның ішінде:

      салықтық түсімдер 3945 мың теңге;

      трансферттер түсімі 17071 мың теңге, оның ішінде:

      ағымдағы нысаналы трансферттер 955 мың теңге;

      субвенциялар 16116 мың теңге;

   2) шығындар 21016 мың теңге;

   3) таза бюджеттік кредиттеу 0 теңге;

   4) қаржы активтерімен операциялар бойынша сальдо 0 теңге;

   5) бюджет тапшылығы (профициті) (-) 0 теңге;

   6) бюджет тапшылығын қаржыландыру (профицитін пайдалану) 0 теңге.

4. 2019-2021 жылдарға арналған Қарабұлақ ауылдық округінің бюджеті тиісінше осы шешімнің 10, 11, 12-қосымшаларына сәйкес, оның ішінде 2019 жылға келесі көлемдерде бекітілсін:

   1) кірістер 19347 мың теңге, оның ішінде:

      салықтық түсімдер 3729 мың теңге;

      трансферттер түсімі 15618 мың теңге, оның ішінде:

      ағымдағы нысаналы трансферттер 955 мың теңге;

      субвенциялар 14663 мың теңге;

   2) шығындар 19347 мың теңге;

   3) таза бюджеттік кредиттеу 0 теңге;

   4) қаржы активтерімен операциялар бойынша сальдо 0 теңге;

   5) бюджет тапшылығы (профициті) (-) 0 теңге;

   6) бюджет тапшылығын қаржыландыру (профицитін пайдалану) 0 теңге.

5. 2019-2021 жылдарға арналған Қарқара ауылдық округінің бюджеті тиісінше осы шешімнің 13, 14, 15-қосымшаларына сәйкес, оның ішінде 2019 жылға келесі көлемдерде бекітілсін:

   1) кірістер 20353 мың теңге, оның ішінде:

      салықтық түсімдер 3086 мың теңге;

      трансферттер түсімі 17267 мың теңге, оның ішінде:

      ағымдағы нысаналы трансферттер 1955 мың теңге;

      субвенциялар 15312 мың теңге;

   2) шығындар 20353 мың теңге;

   3) таза бюджеттік кредиттеу 0 теңге;

   4) қаржы активтерімен операциялар бойынша сальдо 0 теңге;

   5) бюджет тапшылығы (профициті) (-) 0 теңге;

   6) бюджет тапшылығын қаржыландыру (профицитін пайдалану) 0 теңге.

6. 2019-2021 жылдарға арналған Ұзынбұлақ ауылдық округінің бюджеті тиісінше осы шешімнің 16, 17, 18-қосымшаларына сәйкес, оның ішінде 2019 жылға келесі көлемдерде бекітілсін:

   1) кірістер 19986 мың теңге, оның ішінде:

      салықтық түсімдер 3908 мың теңге;

      трансферттер түсімі 16078 мың теңге, оның ішінде:

      ағымдағы нысаналы трансферттер 955 мың теңге;

      субвенциялар 15123 мың теңге;

   2) шығындар 19986 мың теңге;

   3) таза бюджеттік кредиттеу 0 теңге;

   4) қаржы активтерімен операциялар бойынша сальдо 0 теңге;

   5) бюджет тапшылығы (профициті) (-) 0 теңге;

   6) бюджет тапшылығын қаржыландыру (профицитін пайдалану) 0 теңге.

7. 2019-2021 жылдарға арналған Шырғанақ ауылдық округінің бюджеті тиісінше осы шешімнің 19, 20, 21-қосымшаларына сәйкес, оның ішінде 2019 жылға келесі көлемдерде бекітілсін:

   1) кірістер 56722 мың теңге, оның ішінде:

      салықтық түсімдер 4020 мың теңге;

      трансферттер түсімі 52702 мың теңге, оның ішінде:

      ағымдағы нысаналы трансферттер 4455 мың теңге;

      субвенциялар 48247 мың теңге;

   2) шығындар 56722 мың теңге;

   3) таза бюджеттік кредиттеу 0 теңге;

   4) қаржы активтерімен операциялар бойынша сальдо 0 теңге;

   5) бюджет тапшылығы (профициті) (-) 0 теңге;

   6) бюджет тапшылығын қаржыландыру (профицитін пайдалану) 0 теңге.

8. Осы шешімнің орындалуын бақылау Кеген аудандық мәслихатының «Жергілікті өзін-өзі басқару, әлеуметтік және экономикалық даму, бюджет, сауда, тұрмыстық қызмет көрсету, шағын және орта кәсіпкерлікті дамыту, туризм жөніндегі» тұрақты комиссиясына жүктелсін.

9. Осы шешім 2019 жылдың 1 қаңтарынан бастап қолданысқа енгізіледі.
